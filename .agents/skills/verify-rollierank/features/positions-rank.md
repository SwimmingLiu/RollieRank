# 报考岗位与练习榜

验证用户从入口完成操作后的真实结果，并核对持久化的业务状态。

## Sub-features

国考省考岗位表、来源、分层选岗、搜索分页、路径回退、首次提交提醒；国考／省考入口、按年度地区显示真实目录、未导入省考空态；个人岗位、全国、临时岗位；正式交卷自动入榜、最高分、并列与题型最佳。

## How to get to it (user POV)

手机练习记录的报考岗位卡、首次提交提醒、成绩卡的同卷练习榜；基础入口我的记录与报告榜单入口。

## Driving it with verification CLI

Preconditions: 已按主Skill安装依赖；CLI启动隔离服务并通过doctor；不复用4781的日常数据。

运行 `npm run verify -- feature positions-rank`。先切换国考、省考，检查省考缺目录空态及两省目录隔离，再按类别、部门、单位和岗位点击选择，回退后换条件；在同卷榜切换全国及其他岗位并确认个人岗位未变，正式交卷后自动上榜，核对同人多次只保留最高分；页面不应出现上榜设置或版本号。右上角「榜单规则」图标可展开说明；范围按钮的可访问名称为「我的岗位」「全国」「其他岗位」。本人进入前三时不重复本人卡。

证据保存在输出目录的日志、浏览器截图、ARIA快照和结果JSON中。命令非零退出即为未通过，不能把缺少依赖记成成功。

## Gotchas

岗位ID为不透明字符串；只读浏览不可改个人选岗；未配置Excel依赖必须报错而非跳过。

未选岗的默认查询与高亮都应为全国；切回报告再返回保留用户明确选择的范围。用第二期地市与副省分别验证身份条，年份、半年、期次、卷类与套号必须对应实际卷，不能只验证第一期短名称。

判断推理榜合并图形推理、定义判断、类比推理、逻辑判断，按完整板块总得分／总满分选择单次最佳答卷，不能拼接四类最佳或平均得分率。

原生选岗从练习记录、交卷提醒或同卷榜打开面板。使用国考实表沿年度、类别、部门、单位进入职位，打开详情并保存，再从同卷榜临时查看另一个岗位。切换省考确认空态，返回记录时核对本人岗位。

原生面板不另设标题关闭行。列表上拉展开，顶部下滑收起，再下滑退出；点击外部空白直接关闭。职位详情去掉复制链接按钮，左滑回列表。320 短屏还要核对底栏和手势区没有遮住末项。
