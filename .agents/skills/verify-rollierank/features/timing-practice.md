# 做题计时与完整录答

## Sub-features

机构／系列期数／套卷选择、套卷与自定义双向切换、整卷与模块计划、自定义整数分钟与微调、开始暂停继续、模块切换、刷新恢复、结束并录答、计划偏差复盘；列表／单题模式、章节、逐题标记、回看和留空交卷。

## How to get to it (user POV)

首页独立的「开始做题计时」卡片，进行中从「继续做题计时」恢复。先在套卷／自定义间双向切换，套卷按机构、系列期数和具体卷选择；所选卷时限来自题本，只有自定义才可调整总分钟。录答页可切换模式、章节和待检查题，每题可点「存疑」，底部答题卡同步显示标记。结果卡后出现做题用时摘要，点击展开模块差值。

## Driving it with verification CLI

运行 `npm run verify -- feature timing-practice`。在隔离真实手机页面选择机构和系列再选卷，核对 120 分钟原卷时限、整数模块、拖动和键盘排序以及合计差值禁用；双向切换套卷／自定义并保留各自状态。在自定义直接填写整数分钟或使用微调后开始，暂停并刷新，确认暂停期间不累计；继续后切换模块并结束录答。单题左右滑动、选答自动下一题，列表每题可单独标记；刷新保留当前题和标记，答题卡末题可达。先选择继续补答，再明确留空交卷并通过选岗提示；核对真实回执的空白数、原选项和 timing 字段。展开结果用时，重载后确认计划、实际和录答时长保留。

证据在 `test-results/practice-session/`，包括原尺寸界面、真实回执和结果。完整门禁必须执行专项并检查 320／390／430 布局。

原生小程序使用同一份选卷和计时模型。原生验收从首页计时卡进入，用开发者工具确认页面路径保持 `pages/home/home`。机构卡只显示名称，两级目录均不显示套卷总数。操作搜索、机构和期数、切换两类计划、暂停重开、关联录答，核对真实回执。`npm --prefix mini-program run build:timer` 更新原生包中的共享模块，完整门禁会核对版本一致。所有计时列表隐藏视觉滚动条，但保留触屏滚动、搜索和遮罩返回。

原生计时先显示机构，再进入按期数排列的目录；期数用数字顺序，不把「第10期」排在「第3期」前。路径中的返回只保留图标，机构名只出现在机构层。从首页卡进入后，继续录答必须恢复保存的套卷计划，不能因为保存了选择就跳过层级。

## Gotchas

计时须显式开始和结束，暂停不计，模块切换前结算当前模块；录答耗时单独保存。普通录答不根据提交时间推算做题时长。重试提交使用同一个练习凭证和冻结用时。计时进行中先结束做题再录答案。漏答交卷必须由用户明确确认，关闭面板不会提交。

`data/booklet-time-limits.json` 记录 62 份原题本的时限页及 SHA；导入器核对原件后才赋予真实时限。专项覆盖 `test/booklet-time-limits.test.js`、`test/timer-paper-picker.test.js` 和 `test/timer-configuration.test.js`。

`test/ios-timer-entry-feedback-browser.test.js` 另检查选卷→自定义→切回原卷的分钟及顺序恢复，真实 320×568 的模块可见区、键盘尺寸下的输入避让、开始及恢复后的主时钟、模块／整卷计划含义和可见的「存疑／待检查」操作。320 窄屏不能使用 844px 高度代替短屏。

最新选卷层级支持明确的左滑返回上一级，根级返回首页；纵向滚动、搜索框与短拖动不能误触返回。条目为 16px 简洁单行。第 130 题的左右手势须在缩放画廊 iframe 中操作鼠标与触屏验证。连续加减后直接输入、逐位输入及焦点保留由最新回归覆盖。

遮罩位置必须单独验证：在列表已到卷号层级时，从面板上方全屏「关闭面板」遮罩开始并结束左滑，鼠标与原生触摸都只退一级且面板仍打开。普通点击仍关闭；纵向移动不误退；退出选卷器后恢复遮罩样式与事件。
