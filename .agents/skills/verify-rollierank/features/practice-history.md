# 录答、评分、复盘与本机记录

旧历史迁移只删除身份、完成状态和答案均匹配已知演示种子的记录。旧编号不能单独作为删除依据；上一轮可恢复归档里的自有练习须恢复一次，不能覆盖当前更新版本。`test/preview-history-recovery.test.js` 与真实 iframe 记录页检查共同验证恢复、去重和空结果。

验证用户从入口完成操作后的真实结果，并核对持久化的业务状态。

## Sub-features

A–D及键盘录答、列表／单题、章节导航、标记标记、自动跳题、答题卡、批量粘贴、草稿恢复和明确留空交卷；漏答、失败重试、去重；120/130/135题、交卷自动计分和静态示例标记；历史、筛选、身份认领、备份恢复和删除。

## How to get to it (user POV)

手机首页近期练习、机构套卷卡、练习记录；基础入口套卷详情或开始练习、我的记录。

## Driving it with verification CLI

Preconditions: 已按主Skill安装依赖；CLI启动隔离服务并通过doctor；不复用4781的日常数据。

运行 `npm run verify -- feature practice-history`。点击真实答题按钮并重载草稿，打开答题卡访问末题；提交后核对服务端分数与原选项，复盘筛选并导出，再备份恢复和删除隔离记录。

证据保存在输出目录的日志、浏览器截图、ARIA快照和结果JSON中。命令非零退出即为未通过，不能把缺少依赖记成成功。

## Gotchas

手机和基础入口有独立浏览器存储；已知预置历史迁出并保留可恢复档案，真实回执和用户修改过的草稿继续保留。

原生练习记录没有数据时只显示「没有练习记录」，不增加同义按钮或空卡片。筛选后无结果仍用短文本说明。

计时、模式切换、标记回看和留空交卷的完整配方另见 [做题计时与完整录答](timing-practice.md)。
