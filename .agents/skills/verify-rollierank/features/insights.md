# 群体分析与公开成绩

## Sub-features

同卷同版本的 A–D 与留空分布、分数段筛选、个人与群体六板块得分率、全国与岗位范围、超越百分比、公开成绩摘要和撤回权限。

## How to get to it (user POV)

手机真实报告的能力概览右侧「分数段能力对比」图标；逐题对照的题号按钮；同卷榜成员卡的「查看…公开成绩」。示例不提供真实统计入口。

## Driving it with verification CLI

运行 `npm run verify -- feature insights`。CLI 使用隔离真实服务；本人通过手机录答并交卷，其他候选人通过公开提交接口生成真实回执并自动上榜。打开能力对比，切换全国／同岗及分数段，核对「我的」与「全国均值／同岗均值／同段均值」的真实数值。空样本保留本人值，均值显示 —。点击题号查看本人／参考、A–D 和留空分布，验证数量之和等于样本量，再切题和切段。打开榜单成员卡，核对当前范围、总分、六板块和严格低于比例；历史撤回后公开详情立即不可访问。

证据保留在 `test-results/insights-browser/`，包括实际响应、320／390／430 原尺寸截图、布局几何和错误日志。完整门禁会执行相同测试。长昵称名次必须单行，选项标签与横条不得重叠。

## Gotchas

每个身份只取真实答卷中的完整最佳总分单次，不能拼接子型最佳。题型排行榜仍按该板块最佳；成员公开详情展示完整最佳总分答卷。正式提交默认纳入统计，样例排除。分母包含留空，零样本分布及均值为 null；界面只显示人数。公开详情显示上榜昵称，不返回选项、身份凭证或私人答卷编号。答案订正后重新从当前回执聚合。

复盘表头与每题直接显示全国答对率，错题再显示同错率；全部／错题复用同一全卷请求，订正后失效，空或失败显示—。分数段对比使用全部实际板块的两列纸卡。
