# 二刷对比与成长分析

验证用户从入口完成操作后的真实结果，并核对持久化的业务状态。

## Sub-features

报告首刷隐藏摘要、二刷VS、三刷曲线；同考试类别跨机构、整体题型、得分得分率正确率；主题日期日历、来源筛选、单一考试类别与计分帮助、分页同时间点、键盘选点和订正同步。

## How to get to it (user POV)

手机练习记录（小程序为个人中心）的成长分析、二刷报告的完整分析入口；基础入口报告或我的记录内的成长分析入口。

## Driving it with verification CLI

Preconditions: 已按主Skill安装依赖；CLI启动隔离服务并通过doctor；不复用4781的日常数据。

运行 `npm run verify -- feature analytics`。先后提交同卷三次，核对VS和真实曲线；跨机构练习后选择考试类别与资料分析，检查数值、记录表和筛选结果。打开题型点选、三行筛选纸卡和计分说明；从日历选择起止日期、切换月份、用方向键选日，验证非法范围、应用和清除。一次练习显示进度环，多次显示曲线。

证据保存在输出目录的日志、浏览器截图、ARIA快照和结果JSON中。命令非零退出即为未通过，不能把缺少依赖记成成功。

## Gotchas

同满分不代表同评分规则；毫秒时间相同的记录都必须可访问；不能使用示例历史补出趋势。

四类判断子型在题型筛选、VS、权重说明和趋势中统一为判断推理；旧分型记录与当前记录可比较，各条记录使用自己的逐题权重和题型满分。

同卷分数段群体比较的入口、分母和公开样本口径见 [群体分析与公开成绩](insights.md)。

国考／已知公考模拟卷按产品题量规则分为地市卷（130题）和副省卷（135题）；两项即使零记录也保留可选。选择类别后，应同时包含花生与粉笔等不同权重签名的对应记录，图中各点与题型率依各自实际报告计算。界面只有考试类别、来源和日期，没有同类分值层；标准题量卷不显示类别未注明或共用桶。真正的自定义／非标准题量按独立格式保留。同卷二刷仍按自己的前次答卷比较。
