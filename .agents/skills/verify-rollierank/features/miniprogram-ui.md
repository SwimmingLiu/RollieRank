# 微信小程序

原稿构建以 `/ios-v3/app.html` 为唯一界面来源。原生页面承接微信导航、保存相册和同卷转发。原生备用入口仍由 `mini-program/app.json` 登记。

运行 `npm run verify -- feature miniprogram-ui`，检查旧记录和草稿的接续、一次性连接凭证、同卷邀请以及四种海报。浏览器流程加载真实原稿和隔离 API，仅替代微信相册和聊天转发的调用边界。完整门禁也运行这一流程。

| 原稿入口 | 验收内容 |
| --- | --- |
| 首页和套卷 | 最近练习、机构、系列、卷别、卷卡状态和返回位置 |
| 首页计时 | 原生和网页都在首页打开计时面板。检查套卷与自定义、搜索和三级选卷、分钟输入、模块排序、平衡、开始、暂停、恢复、关联录答和用时复盘 |
| 录答案 | 列表、单题、左右滑动、章节、存疑、五列分组答题卡、草稿、漏答确认、选岗提醒与正式回执 |
| 报告和逐题对照 | 真实得分、六板块雷达、逐题与同错率、参考答案反馈、题号分布、分数段、岗位范围、二刷和多刷 |
| 排名和岗位 | 全国、本人、临时岗位、题型榜、公开成绩摘要、国考与省考空态、搜索、面包屑与确认 |
| 讨论 | 长文、照片、自动链接、点赞、分层回复、页内展开、草稿和失败重试 |
| 练习记录和成长 | 历史与草稿、搜索、同卷多次、考试类别、日期、来源、指标和题型 |
| 纠错和审核 | 反馈、依据、试算、审核和驳回、重算及同步 |
| 分享 | 长图、成绩卡、题型和雷达的 PNG、预览边界、保存、同卷转发 |

原生验收用 `cli auto --project <隔离构建目录> --auto-port <端口>`。将此构建的接口指向隔离服务，给 `mini-program/tools/flow.mjs` 传入 `MINIPROGRAM_API_BASE`、`MINIPROGRAM_AUTOMATION_PORT` 和 `MINIPROGRAM_REVIEW_TOKEN`。流程按真实入口核对交卷、反馈、试算、审核重算、记录布局和选岗，保留错误、检查结果和原尺寸截图。

用 `npm --prefix mini-program run build:shared -- <应用源> <新输出目录>` 可另行构建内嵌原稿版。该入口需要源站页面、接口和微信业务域名校验。验收取同一份答卷、同一显示状态和相同窗口宽度，微信状态栏、胶囊和底部手势区单独核对。开发者工具截图与手机实测分别留证。

原生首页将原图标和「卷卷小榜」放在标题栏左侧，对齐微信胶囊的中心线。子页在同一行显示返回、标题和页面操作，至少保留 44px 点击区。检查 320、390、430 宽度的换行、遮挡和操作结果。内嵌原稿版由微信提供系统标题栏。

在微信开发者工具里延迟小程序连接，检查原生页显示原品牌和占位纸卡。微信浏览器流程分别延迟连接凭证兑换和套卷请求，在 320、390、430 宽度截图，确认占位卡贯穿等待过程。原生首次使用加载完成后显示空态纸卡和选卷入口，有练习记录时显示真实最近练习。

从首页进套卷，打开期数选项并点击遮罩。重开后切换到另一套卷，确认当前选项和套卷数据同步。复盘板块列表在短屏上上拉展开，滚动后可选最后一项，下滑回到初始高度。全站列表无可见标题、关闭图标和滚动条。

在原稿练习记录点击「编辑个人资料」，检查微信桥发出打开原生页面的操作。微信开发者工具里确认设置页仅有昵称，保存后返回记录仍保留原练习。测试库检查昵称和头像落盘、凭证隔离，手机号只在已配置时出现并只返回尾号。

使用连接隔离 API 的原生构建，在微信开发者工具点击首页计时卡。停留在 `pages/home/home` 时检查背景、标题与关闭、两个标签、搜索和四家机构。检查窄屏内部滚动、层级返回、重新打开后的暂停状态及卷号和分钟。交卷后读取对应回执，核对做题与录答分别计时。全量门禁另校验原生包中的共享计时模块来自当前原稿。

原生答题卡按题型分组，390 和 430 宽度每行五格，320 宽度每行四格。当前题、已答和存疑各有独立状态。成长分析提供来源和日期筛选。逐题对照可选题并提交建议答案和核对依据。所有页面和组件隐藏滚动条，保留滚动手势。

没有 web-view 业务域名的 AppID 默认进入原生页面。发布构建必须核对 `WEB_APP_ORIGIN` 为空，并在开发者工具确认首页路径为 `pages/home/home`、页面里没有 `web-view`。企业主体完成业务域名校验后才可改用原稿网页入口。
