# 微信小程序

原稿构建以 `/ios-v3/app.html` 为唯一界面来源。原生页面承接微信导航、保存相册和同卷转发。原生备用入口仍由 `mini-program/app.json` 登记。

运行 `npm run verify -- feature miniprogram-ui`，检查旧记录和草稿的接续、一次性连接凭证、同卷邀请、四种海报，以及 `npm --prefix mini-program run check` 的原生静态与安卓无 `Intl`/ES2020 沙箱启动门禁。浏览器流程加载真实原稿和隔离 API，仅替代微信相册和聊天转发的调用边界。完整门禁也运行这一流程。

安卓微信精简 V8 引擎默认不包含 `Intl` 对象，模块顶层直接调用 `new Intl.Collator` 等接口会导致首页 `Page(...)` 注册失败而直接白屏。`mini-program/tools/check.mjs` 与 `test/miniprogram-timer.test.js` 在移除 `Intl`、`Array.prototype.at` 与 `String.prototype.replaceAll` 的独立沙箱中逐一加载 `app.js`、全部已注册页面、`components/*`、`custom-tab-bar/index.js` 和 `vendor/practice-timer.js`，强制校验零报错并完成注册；同时 `check.mjs` 校验 `tabBar.custom: true` 时具备合规 `custom-tab-bar` 组件、全站 `wx.showModal` 按钮文案不超过 4 字符、以及所有 `wx.canvasToTempFilePath` 调用显式传入 `destWidth` 与 `destHeight`。全站复制动作统一通过 `mini-program/utils/clipboard.js` 与纸卡主题提示组件 `rr-toast` 完成（屏蔽微信原生英文/灰底弹窗）。

开发版和体验版使用测试 HTTPS，只有正式版使用生产 HTTPS。用开发者工具核对运行包版本、API 地址和存储前缀，再扫码在开发版或体验版录答，并在测试库查回执。测试域名必须返回测试环境标识，缺少标识时不得交卷、写评论或保存资料。首次正式发布前执行[生产首发检查](../../../../deploy/README.md#首次上线检查)。

| 原稿入口 | 验收内容 |
| --- | --- |
| 首页和套卷 | 最近练习、机构、系列、卷别、卷卡状态、返回位置，以及首页与个人中心（原稿为练习记录）之间左右滑动切换一级菜单 |
| 首页计时 | 原生和网页都在首页打开计时面板。检查套卷与自定义、搜索和三级选卷、分钟输入、模块排序、平衡、开始、暂停、恢复、关联录答和用时复盘 |
| 录答案 | 列表、单题、带滑动动效的左右滑切题、章节、存疑、五列分组答题卡、拍照扫卡、草稿、漏答确认、选岗提醒与正式回执 |
| 报告和逐题对照 | 真实得分、六板块雷达、逐题与同错率、参考答案反馈、题号分布、分数段、岗位范围、二刷和多刷 |
| 排名和岗位 | 全国、本人、临时岗位、题型榜、公开成绩摘要、国考与省考空态、搜索、面包屑与确认 |
| 讨论 | 长文、照片、自动链接、点赞、分层回复、页内展开、草稿和失败重试 |
| 个人中心与成长 | 历史与草稿、搜索、同卷多次、考试类别、日期、来源、指标和题型；原生个人中心另含卷豆、意见反馈与 UID 复制入口 |
| 纠错和审核 | 反馈、依据、试算、审核和驳回、重算及同步 |
| 分享 | 长图、成绩卡、题型和雷达的 PNG、预览边界、保存、同卷转发 |

原生验收用 `cli auto --project <隔离构建目录> --auto-port <端口>`。按[小程序测试环境](../../../../mini-program/README.md#测试环境)生成构建，给 `mini-program/tools/flow.mjs` 传入 `MINIPROGRAM_API_BASE`、`MINIPROGRAM_AUTOMATION_PORT` 和 `MINIPROGRAM_REVIEW_TOKEN`。流程在写入前核对 `/api/catalog` 的测试标识和开发者工具实际运行包的 API 地址，然后检查交卷、反馈、试算、审核重算、记录布局和选岗，保留错误、检查结果和原尺寸截图。

接口联调用 `MINIPROGRAM_API_BASE=http://127.0.0.1:4175 node mini-program/tools/e2e.mjs`。场景校验缺少测试标识、指向生产或返回跳转的目标会在写入前退出。共享测试实例的部署及持久化验收见[测试后端](../../../../deploy/README.md#测试后端)。

用 `npm --prefix mini-program run build:shared -- <应用源> <新输出目录>` 核对源站并按当前配置生成原生验收包。启用内嵌原稿还需要微信业务域名校验和发布配置。运行原生自动化需在宿主安装 `miniprogram-automator`。验收取同一份答卷、同一显示状态和相同窗口宽度，微信状态栏、胶囊和底部手势区单独核对。开发者工具截图与手机实测分别留证。

原生首页将原图标和「卷卷小榜」放在标题栏左侧，对齐微信胶囊的中心线。子页在同一行显示返回、标题和页面操作，至少保留 44px 点击区。检查 320、390、430 宽度的换行、遮挡和操作结果。内嵌原稿版由微信提供系统标题栏。

首页最近练习使用单层右侧错位纸张、小型齿孔年份邮票和底部居中的双箭头上滑提示。卡内只显示机构、期数、卷名、完成进度、插画和进入动作。向上拖动时当前卡跟随手势并轻微缩小，松手后下一张从底部接上；单张记录只显示一张卡，不出现虚假的切换提示。

在微信开发者工具里延迟小程序连接，检查原生页显示原品牌和占位纸卡。微信浏览器流程分别延迟连接凭证兑换和套卷请求，在 320、390、430 宽度截图，确认占位卡贯穿等待过程。原生首次使用加载完成后显示空态纸卡和选卷入口，有练习记录时显示真实最近练习。

从首页进入花生套卷。顶部期数封面卡集中展示期数标题、共享规格（套数、题量、时长）与完成进度条；下方 12 套采用双列单行水平精装卷卡（每卡约 66px 高，整屏刚好排下 6 行），未录答卡左大号衬线卷号右圆钮箭头、已估分与录入中卡用左编号方印配右分数或进度条，零重复文字、整张卡可点。期数按编号递增，同期普通卷在副省级卷前。从隔离目录发布至少十个期数，上拉展开，滚动到末项后点选。从列表顶部下滑，确认面板回到初始高度。点遮罩关闭并保留当前期数。选项只显示标题，面板隐藏滚动条。

原生目录的系列必须对应 .raw 的题本目录。超格 10 套、粉笔 6 套、上岸村 10 套各自保持一个系列入口，130题版、135题版只描述题量，不能把同一文件夹拆成两个期次；花生一期、二期地市、二期副省按「第1期 / 第2期（地市）/ 第2期（副省）」区分展示。上岸村卷卡去掉重复的机构前缀与重复「公考」，统一使用大号数字 + 简短卷别单位的纸卡排版。

在原稿练习记录点击「编辑个人资料」，检查微信桥发出打开原生页面的操作。微信开发者工具里确认设置页仅有昵称，保存后返回记录仍保留原练习。测试库检查微信昵称和头像落盘（配置七牛 OSS 时上传至 OSS、不存 base64，未配置时降级本机）、凭证隔离，评论区头像与用户名实时同步，手机号只在已配置时出现并只返回尾号。

使用连接隔离 API 的原生构建，在微信开发者工具点击首页计时卡。停留在 `pages/home/home` 时检查背景、标题与关闭、两个标签、搜索和四家机构。检查窄屏内部滚动、层级返回、重新打开后的暂停状态及卷号和分钟。交卷后读取对应回执，核对做题与录答分别计时。全量门禁另校验原生包中的共享计时模块来自当前原稿。

原生答题卡按题型分组，390 和 430 宽度每行五格，320 宽度每行四格。当前题、已答和存疑各有独立状态。成长分析提供来源和日期筛选。逐题对照可选题并提交建议答案和核对依据。所有页面和组件隐藏滚动条，保留滚动手势。所有底部弹窗统一暖纸白圆角外壳（`#fffdf8`、`1px solid #ebe2d3`、`24px` 顶部圆角、暖白磨砂遮罩与顶部 `40×4px` 拖拽条），并支持 iPhone 风格 1:1 跟手拖动、顶部橡皮筋阻尼、遮罩透明度联动及距离/速度下滑关闭。

没有 web-view 业务域名的 AppID 默认进入原生页面。发布构建必须核对 `WEB_APP_ORIGIN` 为空，并在开发者工具确认首页路径为 `pages/home/home`、页面里没有 `web-view`。企业主体完成业务域名校验后才可改用原稿网页入口。
