# 微信小程序原生页面

入口为 `mini-program/app.json` 登记的 13 个页面。以 `/ios-v3/app.html?design=paper-cards-1114-v3` 为视觉参考，按相同的套卷、记录和窗口尺寸比对正文。微信状态栏、菜单和底部手势区按设备测量。

`npm run verify -- all` 运行原生源码检查和导航尺寸测试。在已登录的微信开发者工具中用 `cli auto --project <path> --auto-port <port>` 打开临时验收项目。将该项目的 API 指向隔离的本机服务。手机预览使用正式配置和 `cli preview --project <path>`。

- 首页打开选卷、切换期数和恢复记录。检查品牌、机构卡、固定标签栏和顶部菜单余量。
- 录答时切换列表和单题，标记存疑，关闭后再打开。确认答案、题号和标记都能恢复。提交后检查报告、同卷榜和逐题对照。
- 逐一打开长图、成绩卡、题型、雷达，检查显示和导出 PNG。长图可以在预览内滑动，其余三种在保存栏上方自动缩放。
- 从记录页进入成长、报考岗位和设置。检查窄屏换行。打开计时，切换来源，开始和暂停后回到首页，再进入确认状态和时间。
- 从报告进入讨论，检查评论输入、发送、回复和图片。使用隔离身份保留原始截图和运行结果。
