# 微信小程序

原稿构建以 `/ios-v3/app.html` 为唯一界面来源。原生页面承接微信导航、保存相册和同卷转发。原生备用入口仍由 `mini-program/app.json` 登记。

运行 `npm run verify -- feature miniprogram-ui`，检查旧记录和草稿的接续、一次性连接凭证、同卷邀请以及四种海报。浏览器流程加载真实原稿和隔离 API，仅替代微信相册和聊天转发的调用边界。完整门禁也运行这一流程。

| 原稿入口 | 验收内容 |
| --- | --- |
| 首页和套卷 | 最近练习、机构、系列、卷别、卷卡状态和返回位置 |
| 首页计时 | 套卷与自定义、搜索和三级选卷、分钟输入、模块排序、平衡、开始、暂停、恢复、关联录答和用时复盘 |
| 录答案 | 列表、单题、左右滑动、章节、存疑、答题卡、草稿、漏答确认、选岗提醒与正式回执 |
| 报告和逐题对照 | 真实得分、六板块雷达、逐题与同错率、题号分布、分数段、岗位范围、二刷和多刷 |
| 排名和岗位 | 全国、本人、临时岗位、题型榜、公开成绩摘要、国考与省考空态、搜索、面包屑与确认 |
| 讨论 | 长文、照片、自动链接、点赞、分层回复、页内展开、草稿和失败重试 |
| 练习记录和成长 | 历史与草稿、搜索、同卷多次、订正通知、考试类别、日期、来源、指标和题型 |
| 纠错和审核 | 反馈、依据、试算、审核和驳回、重算及同步 |
| 分享 | 长图、成绩卡、题型和雷达的 PNG、预览边界、保存、同卷转发 |

从仓库根目录用 `npm --prefix mini-program run build:shared -- <应用源> <新输出目录>` 构建原稿版。开发者工具验收用 `cli auto --project <输出目录> --auto-port <端口>`。用真机微信打开前，源站必须提供页面和连接接口，业务域名也须在微信公众平台通过校验。取同一份卷、相同状态和窗口尺寸，微信导航和底部手势区按真机截图单独核对。浏览器或开发者工具的结果不替代真机验收。

首页保留原稿 logo 与「卷卷小榜」组合，紧接在微信胶囊下方。其他页面由微信原生标题栏显示当前页名称，正文不再绘制重复标题或模仿标题栏。返回、重练、反馈和规则分别放在对应内容区，保留可见文字和至少 44px 点击区。检查 320、390、430 宽度的换行、遮挡和操作结果，并用微信模拟器截图核对系统标题与胶囊。

在微信开发者工具里延迟小程序连接，检查原生页显示原品牌和占位纸卡。微信浏览器流程分别延迟连接凭证兑换和套卷请求，在 320、390、430 宽度截图，确认占位卡贯穿等待过程。首次使用加载完成后显示选卷入口，有练习记录时显示真实最近练习。
