# 卷卷小榜 · 微信公众号自动化运营接入说明

仓库已经内置完整的微信公众号自动化运营流水线（[scripts/wechat-mp/](../scripts/wechat-mp)）：从线上 `/api/catalog` 自动拉取真实 62+ 套卷分值表，生成适合微信 AI 搜索（GEO）抓取的结构化图文与暖纸风封面图，并自动推送至微信公众号草稿箱。

---

## 一、首次接入（3 分钟开启全自动草稿箱推送）

登录微信公众平台（`https://mp.weixin.qq.com/`）做完以下 3 项配置后，即可由程序自动推送草稿箱：

1. **关联小程序（让正文卡片与菜单直达「卷卷小榜」）**
   - 路径：左侧菜单 → **广告与服务 → 小程序管理 → 关联小程序**
   - 搜索并绑定 AppID：`wx7febd9298bcc5b9b`（卷卷小榜）。
2. **获取公众号开发者密钥 & 加 IP 白名单**
   - 路径：左侧菜单 → **设置与开发 → 基本配置**
   - 复制公众号的 `开发者ID(AppID)` 与 `开发者密码(AppSecret)`（注意不是小程序的 AppID）。
   - 在同一页面的 **IP白名单** 中填入：
     - 腾讯云固定服务器 IP：`118.25.65.206`（推荐长期跑定时任务）
     - 若需在本机直接推草稿箱，一并填入本机出口 IP（可在终端运行 `curl -s https://api.ipify.org` 查看）。
3. **写入 `.env` 并一键校验**
   在仓库根目录 `.env` 追加两行（勿提交到 Git）：
   ```env
   WECHAT_MP_APP_ID=你的公众号AppID
   WECHAT_MP_APP_SECRET=你的公众号AppSecret
   ```
   运行检查与同步：
   ```sh
   npm run mp:check   # 校验凭证、IP 白名单与草稿箱权限
   npm run mp:sync    # 把全部 9 篇图文、9 张封面图和小程序卡片自动推入公众号草稿箱
   ```

> **关于个人主体未认证订阅号的权限边界**：
> - `draft/add`（写入/更新草稿箱）和素材上传通常可用，程序会自动完成排版、传图、插入 `<mp-miniprogram>` 小程序卡片并写入草稿箱。
> - `freepublish/submit`（直接群发发布）微信官方仅对已认证号开放；个人号执行 `npm run mp:sync -- --publish` 时会自动识别并把文章留在草稿箱，每天进后台点一次「发表」即可（按 `.local/wechat-mp/content-calendar.md` 排期每天发 1 篇）。

---

## 二、零配置立刻也能用（一键复制运营台）

即使暂时还没填公众号 AppSecret，运行 `npm run mp:generate` 后已生成本地预览台：
- 打开 `.local/wechat-mp/preview.html`
- 每篇文章均支持**一键复制微信富文本排版**（100% 内联 CSS，粘进公众号后台格式零丢失）、复制标题/摘要/小程序路径，以及下载对应 900×383 暖纸风封面图（位于 `.local/wechat-mp/covers/`）。

---

## 三、自动回复与底部菜单配置

每次生成会自动输出 `.local/wechat-mp/mp-backend-config.json`（预览台顶部也能一键复制）：
- **关注后自动回复**：欢迎语 + 引导回复【估分】【分值表】【花生】【超格】【粉笔】【上岸村】【排名】。
- **4 组关键词自动回复**：覆盖估分入口、130/135 分值表、四大机构模考、同卷排名规则。
- **底部 3 栏自定义菜单**：「行测估分」（直达小程序首页）、「机构模考」（直达 4 家机构套卷目录）、「算分指南」（直达独立站 3 篇专题页）。已认证号可运行 `npm run mp:sync -- --sync-menu` 一键同步菜单；个人号在后台「内容与互动 → 自定义菜单」照抄配置一次即可。

## 四、无人值守定时巡检（自动追新卷）

```sh
# 手动触发一次全链路巡检（生成新卷图文 -> 推公众号草稿箱 -> 推小程序搜一搜）
npm run mp:autopilot

# 在本机 macOS 安装每天 09:00 自动巡检任务
bash scripts/wechat-mp/install-cron.sh --install-launchd

# 查看服务器 crontab 配置（推荐在固定 IP 服务器 118.25.65.206 上部署）
bash scripts/wechat-mp/install-cron.sh --print-server-cron
```
