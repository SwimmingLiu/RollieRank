# 统一选岗入口与判断推理统计

选岗提示现以「选岗查看同岗排名」作为唯一标题，只保留「去选岗」「先提交」两个动作。来源首层提供国考、省考切换，按真实目录显示年度和地区；未导入省考表时显示空态。打开来源层会重新读取目录，因此维护者后来导入的省考表可立即出现。

逻辑判断、类比推理、图形推理和定义判断在报告、榜单、成长分析、答题卡和导出中统一为判断推理。分数按全部题目的原始权重汇总；榜单选取单次完整板块的最佳答卷，避免拼接各子型最佳成绩。折算卷先汇总原始整数再换算，旧快照也使用同一规则。服务端原始题目、答案及作答记录保留。

全局滚动条改为2px低对比暖灰，使用最多56px的原生可见轨道。浏览器验收显式开启原生滚动条，核对实际占用宽度、滚轮到底和滑块拖回顶部，并处理画廊缩放下的实际指针坐标。

验证结果：完整门禁8个阶段通过，183项测试通过且零跳过；基础、连接功能和手机旅程分别通过8、15、12组业务检查。44张原尺寸视觉截图无布局发现和浏览器运行错误。省考专项覆盖国考缓存建立后再导入浙江、广东目录、地区隔离和岗位保存。完整证据保存在test-results/ui-subject-refinement/final。
