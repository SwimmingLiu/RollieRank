# 统一验证方案

项目Skill保存在`.agents/skills/verify-rollierank/`，CLI以Python编排既有Node测试和Playwright旅程。依赖固定版本，缺失即失败；先构建并检查，再在一个隔离Node服务中顺序驱动手机、基础功能和基础管理流程。每次异常重新doctor，清理由创建者负责，日志、截图和业务断言结果保留。

功能图谱覆盖目录管理、练习记录、岗位榜单、交流、分析、纠错和分享。CLI按实际执行的场景记录覆盖；源码审查与真实交互分开。视觉检查在真实视口核对溢出、控件尺寸、图标留位、字体和纸卡主题，并保留原尺寸截图供像素检查。跨平台字体差异不被当作业务通过，动态内容也不靠自动接受基线掩盖。

GitHub Actions安装Node、Python、锁定依赖及Chromium，调用同一完整命令，失败时上传全部证据。AGENTS.md规定完工前的验证和后续Skill维护；远端PR与发布遵循用户已有授权。
