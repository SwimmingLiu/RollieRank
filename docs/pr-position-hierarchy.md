# 真实岗位分类与层级查询

旧岗位目录没有保留原 Excel 的机构性质与考试类别，四张工作表名无法表示实际分类。本次保留两列原文，规范副省级、地市级、行政执法类的显示值，重导入全部 19,426 个官方岗位。既有岗位字段、岗位 ID、来源 SHA、来源元信息和 35,691 个名额保持不变，仅补分类信息并更新派生 JSON 校验和。

新增 `/api/positions/hierarchy`，按来源、类别、招录部门、用人单位和岗位逐层返回。节点 ID 包含父路径，错误或跨父级条件直接拒绝；搜索只作用于当前层，支持 40/100 条分页及 positionId 路径恢复。旧 SchemaVersion 1 缺少类别或单位时以 automatic 节点自然过渡，不从工作表、专业或学历补猜分类。

22 项层级、导入和原服务测试通过，包含原 XLS 逐行分类摘要核对、原岗位 ID 摘要、实际 HTTP 父级校验、已选岗位恢复、重启稳定性，以及原目录、选岗和真实榜单兼容。精确响应与自动过渡语义见 `docs/integration-ios-position-hierarchy.md`。前端与公共入口由协调对话接入，本次没有修改前端。
