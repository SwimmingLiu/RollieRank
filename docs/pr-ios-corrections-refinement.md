# 将答案纠错移入逐题对照，报告仅显示真实订正

报告原先常驻答案反馈卡，普通报告也展示版本与修订号。现在由逐题对照页的独立操作打开反馈表单，可带入题号并继续反馈多题；报告在实际订正后才显示一枚可进入处理详情的状态。空通知区只保留维护者入口。

原工厂公开 openFeedback(questionNumber?) 和本答卷通知的只读副本，iOS 包装新增 reportStatusView()。关闭后再次进入从新反馈开始，失败重试仍保留当前输入。样例保护、服务端授权、审核与原子重算继续使用原链路。

真实 BottomSheet 与 API 的独立 /ios-v3/ iframe 专项通过 7 组场景，覆盖题号预填、多题、取消与遮罩无副作用、试算、授权审核、实际订正状态、处理详情和手机布局；原纠错回归 11 项通过。

精确导出与接入见 [纠错收敛交接](integration-ios-corrections-refinement.md)。公共标题栏、报告挂载与组合验收由协调任务完成，模块与测试证据已按当前源码固定。
