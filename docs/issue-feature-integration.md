# 四项考生功能的公共集成

现有估分原型的成绩快照保存在浏览器，榜单主要使用演示数据，反馈仅能下载文本。选岗、讨论、成长分析和审核订正需要共同使用持久化数据，并接到现有页面和提交流程中。

## 需要解决的问题

四项功能由独立对话实现，公共入口必须统一注册服务和页面钩子，避免重复事件监听及并发写入覆盖。答案订正通过后，历史报告、榜单与成长分析应读取同一份新成绩。已有草稿、历史记录和工作区修改须保留。

## 验收

全国及岗位排行榜只使用真实参与记录；选岗提醒可继续完成提交。讨论刷新后保留文字和媒体。二刷与跨套卷分析使用兼容评分规则。纠错通过后旧记录、未来提交和相关统计使用订正答案，未授权审核被服务端拒绝。原有选卷、作答、导入、成绩导出与备份流程仍可用。
