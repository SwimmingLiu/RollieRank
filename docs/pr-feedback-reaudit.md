# 修复逐项纸卡界面反馈

计时切换曾丢失所选卷，短屏输入与操作栏互相遮挡，评论照片入口和刷新草稿不完整，排名范围及卷身份也不一致。现在按原始批注分别修复这些状态，并补齐内容／遮罩逐级返回、简洁大字条目、存疑题复盘和按题反馈。

成长入口按考试类别组织，同类跨机构汇总并保留各次实际分值。分享年份归入卷身份、品牌作为水印，四模式移除估分小标题，导出雷达保留足够像素。评论使用同栏输入，文字照片与目标草稿跨刷新保留。历史清理仅匹配已知演示种子，旧归档中的自有记录可恢复。

本地完整回归 246 项通过，0 失败、0 跳过；新增真实操作覆盖遮罩鼠标／触摸、缩放画廊末题、快速分钟输入、待检查跨提交、两题反馈、板块跳转、短屏固定操作栏以及导出画布像素。独立视觉复查已确认短屏反馈栏修复。具体逐项结果与证据见 docs/feedback-checklist.md 和 test-results/verification/。实体系统软键盘未实机验证。本文件为本地 PR 草稿。

最新国考练习分类采用130题地市卷、135题副省卷；唯一考试类别筛选会汇总同类不同权重的记录，每次沿用自己的分值。报告入口的初始卷范围在来源筛选明示，切换类别恢复全部对应记录。
