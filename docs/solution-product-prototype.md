# 产品原型实现方案

沿用零运行时依赖的 JavaScript 和 Node.js，复用现有评分规则、答案解析与 12 套已核对答案。浏览器仅接收套卷元数据；提交后由本地服务评分并返回成绩快照。静态资源服务隔离参考答案与运行数据。

| 模块 | 职责 |
| --- | --- |
| `src/app.js`、`styles.css` | 首页、专注答题、报告、明细、排行、个人记录与管理界面 |
| `src/model.js` | 可变题量的整卷校验、定点计分、CSV 导入、公开元数据 |
| `src/prototype-state.js` | 本机草稿、不可变历史、旧草稿迁移、存储失败反馈 |
| `src/leaderboard.js` | 同卷同版本个人最佳、竞赛排名、题型独立最佳 |
| `src/poster.js` | 三种 PNG 海报、公开字段控制 |
| `server/api.mjs` | 目录、幂等评分、本机导入、版本发布、下线、审计 |

首页将最近草稿置顶；筛选按机构、项目、期数、卷别依次生效。提交确认后冻结历史，再次练习创建新记录。报告首屏只展开最低得分率的三项；正确率与得分率分别展示。逐题明细展示本人选项与参考答案，不伪造选项人数分布。

排行使用显式标识的样例用户，体验身份和认领仅在当前浏览器生效。用户可选择参与或退出演示榜。正式微信登录、权限隔离、云同步和公共榜需要后续接入，原型界面不显示虚假的同步成功。

管理端导入任意题量、固定分值单选卷，整批校验通过后保存草稿，经试算预览发布。修订保持题序和题型结构，生成独立规则版本；旧报告保持原快照。

验证包括原有回归、计分/快照/版本/榜单行为测试、接口隔离测试，以及手机与电脑上的录入、刷新续答、提交、导出、分享和管理流程。
