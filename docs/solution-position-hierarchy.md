# 岗位层级数据方案

岗位新增可选字段 institutionCategory、examCategory 和 examCategoryLabel，分别记录原机构性质、原考试类别及规范显示值。机构类别直接采用原列，考试类别按已知官方名称对应副省级、地市级或行政执法类；其他真实类别保留原文。SchemaVersion 1 继续兼容缺少新字段的目录，岗位 ID 计算不变。

新增 hierarchy GET 接口，逐层查询 source、category、department、unit、position。类别由机构类别与考试类别共同分组，部门和单位节点采用包含父路径的稳定哈希 ID，客户端仅回传，不解析。每个 ID 必须在当前父节点内存在，禁止省略中间父条件或使用其他路径的 ID 退回宽范围。

缺少有效分类或单位时返回 label 为空且 automatic 为 true 的过渡节点。仅有一个此类节点时 autoAdvance 为 true，客户端自动继续，不把空类别或空单位画出来。仅有一个来源也可自动进入。已有岗位按 positionId 恢复完整路径与末级同级岗位，页码默认定位到已选岗位所在页。

搜索仅过滤当前父节点内的本层名称与编码；默认每页 40 条，可选择 100 条。所有层级读取均为只读，不改变个人选岗、参与或成绩，原目录、个人设置与榜单接口保持兼容。
