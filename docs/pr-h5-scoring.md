# 新增行测 H5 答案录入与逐题计分

## 背景

仓库原先没有答案录入和计分功能。用户提供了四海 2026 下半年一期的 12 套答案与题本，以及 130 题评分参考，需要按题号匹配题型和分值，输出完整得分结果。

## 解决方案

新增适配手机和电脑的 H5 页面，支持 A–D 点击或键盘连续录入、题号跳转、三种格式的批量粘贴、套卷切换和独立草稿恢复。生成报告时比较配套参考答案，输出总分、九类题型得分和全部 130 题的结果，可筛选并导出 CSV。未答和答错计 0 分；逻辑判断每题 0.85 分，内部使用整数累加。

从 12 份答案 PDF 导入 1,560 个答案，检查题号连续覆盖；从扫描版题本逐套识别判断推理的四个子题型边界，保留 PDF 页码与 SHA-256。原始 PDF 不纳入 Git 和静态产物。

计分、答案解析与界面分开，运行时无第三方依赖。后续可复用计分和解析模块，将视图、存储和下载适配为小程序 API。

## 验证

| 检查 | 结果 |
| --- | --- |
| 自动测试 | 27 项通过，覆盖全部套卷满分／零分、题型边界、混合答案、解析失败、草稿恢复、CSV 和本地服务 |
| 原始答案核验 | 12 套共 1,560 个答案与原始 PDF 一致；题本哈希与边界记录匹配 |
| 浏览器交互 | 点击与键盘连续录入、刷新恢复、跨套卷隔离、重复题号阻止导入、空题确认均通过 |
| 报告复算 | 全对为 100 分；将第 101 题改错后为 99.15 分，错题筛选仅显示该题 |
| 实际文件下载 | CSV 包含 130 条逐题记录，测试样本累计 4.35 分，与页面一致 |
| 手机布局 | 390 × 844 和 320 × 740 视口下页面无横向溢出，成绩表可在容器内横向滚动 |
| 静态构建 | 生成 `dist/`，仅含页面、样式、图标和浏览器模块 |
| 使用说明 | 通过文案检查，提供启动、构建、数据核验及小程序迁移说明 |

浏览器检查使用桌面内嵌浏览器及其响应式视口，未使用微信真机 WebView。草稿仅保存在当前浏览器，不跨设备同步。
