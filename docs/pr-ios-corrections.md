# 在 iOS 界面接入真实反馈与授权审核

/ios-v3/ 原先没有挂载纠错模块，考生无法从实际使用的界面提交反馈或查看订正通知。本次新增 createIOSCorrectionsFeature，复用已经验证的反馈、试算、服务端授权及历史重算逻辑，使用现有 beUI BottomSheet 和白灰珊瑚样式。

个人通知区新增维护者审核入口，管理宿主提供纠错与岗位两个挂载点。原模块增加可选 modalSelector，使 BottomSheet 内的操作在保存期间正确禁用；根应用默认仍使用 dialog[open]。旧样例不能发送正式反馈，凭证只在会话内存中保留。

独立同源 /ios-v3/ iframe 的真实 BottomSheet 专项通过 5 组场景，包含多题提交、失败恢复、保存状态、试算、授权、审核确认、分批结论、双方通知、键盘与手机布局。原纠错回归 11 项通过，iOS 现有模型与 bridge 检查 7 项通过。

精确接入、证据及尚待组合验证事项见 [iOS 纠错交接](integration-ios-corrections.md)。实际用户端口及公共入口由协调任务接入；本地验证使用临时数据与独立端口，没有修改日常数据或创建远端 PR。
