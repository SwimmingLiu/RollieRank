# 岗位目录、选岗与真实练习榜

目前的排行榜由固定样例与本机成绩组成，无法比较服务中真实参与者的成绩，也没有国考、省考岗位目录。考生的岗位和参与选择未同步到服务端。

需要从可核验的官方招考资料建立带年度的岗位目录，在我的练习记录中选岗，提交前允许选岗或明确跳过。排行榜默认展示所选岗位，支持查看全国和其他岗位；查看范围不改变个人选岗。榜单使用服务端提交凭证，按同卷同版本、总分或题型分别取个人最佳，同分并列，参与和撤回均持久化。

Excel 导入保留编码字符串与原始文件来源，区分年度、地区和部门。重复编码、空表、无法识别的列和不可靠的数值编码需要给出可定位的错误。

最新招考年度已核实为 2027 年。公告发布于 2026 年 10 月，资料以获取日 2026-11-14 为准。[国家税务总局上海市税务局转载公告](https://shanghai.chinatax.gov.cn/tax/xxgk/rsxx/202610/t481763.html)、[新华网招考简章附件](https://www.xinhuanet.com/edu/20261014/b1348cb4596a4d3d95323b5dcb751c6a/c.html)。
