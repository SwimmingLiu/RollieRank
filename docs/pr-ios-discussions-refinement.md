# 为本卷评论增加点赞与层内回复

原评论只能单独发表，难以围绕某条解题思路交流。现在可以点赞或取消、回复评论、继续回复他人，并展开或收起同一评论下的回复。目标昵称、真实总数和独立分页保持一致。

手机输入沿用暖纸主题，支持照片、自动链接、自增高与全屏。根评论及各回复对象保留独立草稿，失败重试不会重复发表。返回交流页会刷新已展开的回复，服务端继续兼容历史媒体。

真实 A／B／C 浏览器专项通过，检查了 320／390／430 的 18 张原图。完整门禁 `npm run verify -- all` 已通过 223 项测试，0 失败、0 跳过；当前结果在 `test-results/verification/results.json`。这是一份本地 PR 草稿。
