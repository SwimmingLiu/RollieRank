# 计分口径核对

国家公务员局的 2027 年度招考公告明确公共科目试卷分三类：中央机关及其省级直属机构综合管理类、市（地）级及以下直属机构综合管理类、行政执法类。行测与申论满分均为 100 分。这是考试类别，不能据此推导每个题型或每道题的固定分值。[官方公告转载，来源为国家公务员网](https://www.kashi.gov.cn/ksdqxzgs/c117934/202610/b430bca9d04d489ca39829e2280c497f.shtml)。

2027 年公共科目笔试大纲列出政治理论、常识判断、言语理解与表达、数量关系、判断推理、资料分析六个部分，注明行测时限 120 分钟、满分 100 分；本次核对的公开大纲未列逐题或逐板块分值。[2027 年公共科目笔试考试大纲转载](https://jy.slu.edu.cn/2026/1014/c557a58735/page.htm)。

项目中的机构套卷使用导入分值表，参考卷使用平台参考权重，两者均用于练习估分。界面称为「套卷计分」或「参考估分」，不标注为官方逐题标准。省考按实际省份、年份与来源卷规则处理，不能直接套用国考类别推断分值。

每份练习的得分、满分、得分率和正确率来自它自己的报告。成长分析按考试类别汇总记录，保留各卷逐题权重与实际分母；不会用另一套卷的权重重新计算已有成绩。

## 成长筛选的考试类别

本产品按国考练习卷题量分为地市卷（130 题）和副省卷（135 题），考试类别是唯一的类别筛选。花生、粉笔及其他已知公考模拟卷按这个产品规则归入对应题量类别；机构和系列只用于记录来源。同一类别收录不同参考分值的练习，趋势点与题型得分率使用各自答卷的实际得分和满分。真正的自定义或其他题量卷保留独立格式。

这项产品归类不等于公布官方逐题分值。官方考试公告与大纲的适用范围见上文来源，练习计分仍依据本卷已有分值表。
