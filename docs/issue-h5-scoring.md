# H5 行测答案录入与计分

## 背景与问题

现有仓库尚未提供答题和计分页面。用户提供了 12 份四海 2026 下半年一期行测套题答案表，以及地市级／行政执法类 130 题的评分参考图片，需要将个人答案与套卷答案按题号比较，输出逐题得分。

## 预期行为

- 可切换 12 套试卷，以 A、B、C、D 逐题作答；选后自动定位下一题，也可按题号跳转。
- 可粘贴连续选项、带题号的答案或五题分组答案；空题保留位置，错误格式阻止导入。
- 按题型计分，答错与未答计 0 分，全部正确计 100 分。
- 输出总分、各题型得分及全部 130 题的答案对照、结果和得分，可导出 CSV。
- 手机浏览器可用，各套卷草稿独立保存，刷新后可继续。

## 资料边界

用户补充了 12 份扫描版题本。逐套识别题型标题和其后首题题号，确认全部套卷的图形推理为 76–85 题、定义判断为 86–95 题、类比推理为 96–100 题、逻辑判断为 101–110 题。校验记录保留题本文件哈希和对应 PDF 页码。

本地交付 H5 源码、测试、使用说明与 PR 草稿。用户的原始 PDF 保留在 `.raw/`，不进入构建产物。
