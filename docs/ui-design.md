# 卷卷小榜 · 移动端 UI 设计方案

> 配套高保真稿：[ui-design.html](ui-design.html)
> 基准画板：390 × 844 · 最小触控热区 44 × 44 · 淡紫—淡粉视觉体系（替代现有 H5 墨绿）

## 1. 设计原则

| 原则 | 规则 | 验收 |
|---|---|---|
| 一屏一任务 | 选卷页只找卷；答题页只选答案；报告首屏只回答“多少分、排第几、先补哪项” | 每屏主动作 ≤ 1 |
| 数字先于文字 | 分数、题号、百分比用大号等宽数字；状态用色块 + ✓ / × / · 双编码 | 不读文字也能判断状态 |
| 拇指热区 | 选项、上一题/下一题、生成海报固定在屏幕下半部 | 主要动作落在底部 1/3 |
| 渐进披露 | 题型先给最弱 3 项；逐题统计点击“详细”再展开 | 首屏信息 ≤ 3 组 |

## 2. Design Tokens

### 色彩

| 角色 | 值 | 用途 |
|---|---|---|
| 页面底色 | `#F7F4FA` | 全屏背景（淡紫灰） |
| 卡片 | `#FFFFFF` | 内容容器 |
| 品牌渐变 | `#7E5A9B → #A87399` | 续答卡、主按钮、本人榜卡 |
| 品牌雾紫 | `#6B4C86` | 主按钮、当前态、分数 |
| 雾紫浅底 | `#F0E8F7` | 已答、标签、弱提示 |
| 樱花粉 | `#F3D3E3` | 进度高亮、勾选、强调底 |
| 答错 | `#C2586B` | 错误、负增长（玫红） |
| 待核对 | `#A87336` | 版本更新、待确认 |
| 未答 | `#7A7185` | 空白状态 |
| 分隔线 | `#E8E0EE` | 唯一分隔色 |

状态同时用符号：`✓` 答对 / `×` 答错 / `·` 未答，避免只靠颜色。

### 字号

| 层级 | 大小 | 字重 | 用法 |
|---|---|---|---|
| 成绩 | 40–52px | 650 | 分数主视觉，`tabular-nums` |
| 题号 | 32–34px | 650 | 当前题 |
| 标题 | 16–18px | 600 | 页面/套卷标题 |
| 正文 | 13–14px | 400 | 列表说明 |
| 辅助 | 10–11px | 400 | 时间、题量、规则 |

### 间距与形状

- 间距 4pt 基线：4 / 8 / 12 / 16 / 24。
- 圆角：卡片 16–22px，按钮 14–16px，胶囊 999px；同屏最多两种圆角。
- 分隔只用 1px `#E4E9E1`；卡片靠留白分组，不叠加边框与阴影。
- 底部主按钮高 50px；答题选项高 88px；题号格最小 30×30。

## 3. 页面与组件映射

| 页面 | 首屏只保留 | 收起 / 后置 |
|---|---|---|
| 首页 | 续答卡、机构胶囊、当前期数、3 套卷 | 评分规则、历史成绩、卷别说明 |
| 答题 | 题号、2×2 选项、自动跳题 | 答题卡（底部抽屉）、批量粘贴（抽屉） |
| 报告 | 分数、排名、对错未答、最弱 3 项 | 全部题型、逐题对比、CSV |
| 详细 | 分数段胶囊、每题四选项条形 | 人数不足提示、样本说明 |
| 榜单 | 维度 Tab、前 8 名、本人置底卡 | 规则说明、更新时间 |
| 我的 | 最佳/平均、最近 3 次 | 全部历史、单卷趋势、隐私设置 |

核心组件：`按钮`、`胶囊`、`题号格`、`套卷行`、`进度条`、`成绩卡`、`分段控制`、`提示条`、`空状态`。全部在 HTML 稿第 04 节可视。

## 4. 密度改造

| 旧 | 新 |
|---|---|
| 首页标题 + 说明 + 题数 + 满分 + 版本 + 规则入口 | 续答、机构、期数、套卷四组 |
| 答题页四周说明、键盘提示 | 只留题号与选项；答题卡从底部拉起 |
| 报告一次性铺 6–9 个题型卡 | 最弱 3 项 + “全部 6 项 ›” |
| 榜单每行带头像、日期、明细、击败比例 | 名次、昵称、分数；时间降为小字 |
| 状态靠文字解释 | 色块 + `✓ / × / ·` 双编码 |

## 5. 与现有 H5 的衔接

现有 H5 使用绿色体系，小程序端改为淡紫—淡粉体系，需要替换 CSS 变量而非沿用：

| 现有变量 | 新值 | 用途 |
|---|---|---|
| `--green #245445` | `--brand #6B4C86` | 主色、当前态、分数 |
| `--green-soft #eaf1e8` | `--brand-soft #F0E8F7` | 已答、标签底 |
| `--line #e2e8e1` | `--line #E8E0EE` | 分隔线 |
| `--background #f6f8f4` | `--bg #F7F4FA` | 页面底色 |
| `--radius 18px` | 保持 18px | 卡片圆角基准 |

新增：`--pink #F3D3E3`（高亮）、`--red #C2586B`（答错）、`--amber #A87336`（待核对）。原 H5 的批量粘贴、答题卡、CSV 逻辑保留，只重排视觉与配色。若暂时不改 H5，可先让小程序独立使用新色板。

## 6. 已确认决策

1. 首页：**续答优先**。续答卡置顶，套卷列表紧随其后。
2. 报告首屏：**最弱 3 项**。其余进入“全部 6 项 ›”。
3. 答题页：**隐藏底部 Tab**。只保留返回与答题卡入口。
