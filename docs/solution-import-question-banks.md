# 新增纸质套卷导入方案

保留原有一期数据入口和稳定 ID，扩展导入脚本处理新目录。使用 PDF 文本层提取可复制答案；扫描资料通过本机 OCR 提取，保留页码、识别结果和文件哈希，按完整题号序列与重复识别结果交叉校验。

新增套卷保存机构、项目、期数、卷型、题量、参考答案、题型范围和来源证据。主卷答案与附加差异题分开记录。花生二期按随附的地市卷、副省卷分值图配置；超格、粉笔和上岸村使用平台国考模块参考权重，明确标注参考估分。

参考规则采用政治理论、常识判断每题 0.5，言语理解、判断推理每题 0.8，数量关系、资料分析每题 1 的相对权重。按题本实际题量计算总权重，再统一折算为 100 分。总分用整数权重汇总后四舍五入至两位小数；分项和逐题仅在展示时保留两位。历史快照同时保存原始权重与规则，防止恢复记录时改变成绩。

本地服务加载新增目录时仅补入不存在的版本，不覆盖已保存版本，不改变历史提交。目录只公开元数据与计分说明，参考答案在提交后返回；附加题答案保存在来源数据中，不拼入主卷。

验证包含源文件一致性检查、原有一期答案回归、新卷题型边界与分值验算、参考分数舍入与快照恢复、已有本机数据保留，以及目录、提交、发布和修订接口的实际请求。
