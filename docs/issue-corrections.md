# 答案反馈需要可审核、可追踪的处理链路

结果页当前把反馈下载为文本，服务端没有保存反馈，考生无法查看进度，维护者也没有待审队列。标准答案调整后，历史报告缺少统一的重算和通知。

考生需要针对已提交答卷的一题或多题提交建议答案及核对依据，并查看处理结果。待审反馈可以试算个人成绩；正式答案和正式成绩只在授权审核通过后更新。

维护者需要按题号批量通过或拒绝反馈，填写理由并留下审计。订正答案、重算同版本答卷与保存审计需要作为一次事务完成，失败时恢复原状态。未配置维护者凭证时，服务端应拒绝审核。

交付范围包括纠错服务、结果页入口、个人通知、管理审核区域及行为测试。公共入口接入由协调任务完成，接口约定见 integration-corrections.md。
