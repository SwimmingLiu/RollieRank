# 用原生方格答题卡区分题号与答案

旧答题卡的题号和答案都偏小，长卷末题也需要更明确的定位。新增 mountAnswerSheet，复用现有 beUI Button，以五列圆角方格展示答案；350px 及以下切为四列。题号位于上角，已选答案为主值，当前题使用珊瑚描边。

组件保留真实题型与范围，在自己的滚动列表中定位当前题，提供键盘焦点移动和跳题回调。答案由调用方控制，组件不创建模态，也不修改答案或提交答卷。

严格 TypeScript 检查与真实 React/BottomSheet 专项通过，覆盖 130/135 题、短卷、空集合、键盘、320px、末题、吸顶标题、外层滚动不变及关闭无修改。所有编译产物位于临时目录，公共 vendor 未写入。

精确导出、接入与证据见 [答题卡交接](integration-ios-answer-sheet.md)。公共 app.js、bridge 和组合验收由协调任务负责。
