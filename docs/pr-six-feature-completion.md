# 补齐手机练习、群体分析与评论互动

手机练习原有计时依附套卷、排名需要手动设置，复盘缺少群体选项数据，分享和分析的层级也不够清楚。现在首页提供独立计时，按机构、系列期数与卷号选择试卷，或采用 120／60／30 分钟推荐再调整。模块使用整数分钟，合计校验与拖动排序同步，暂停恢复及录答耗时分别记录。

录答采用纸卡单题界面，支持左右滑动、每次选答后前进，列表和单题均可标记。正式成绩自动上榜，多次保留最佳。复盘直接显示答对率和同错率，详细面板展示 A–D 与留空；能力对比明确区分「我的」和当前范围均值。VS 展示全部实际板块，成长记录数值列对齐。

评论支持点赞和层内回复、展开收起及分页，保留照片、自动链接、输入增高和全屏。分享提供四种真实 PNG，自动适配预览，使用指定透明 Logo；导航、底栏对齐和空状态同时完成精简。旧设计历史通过可恢复迁移清理。

`npm run verify -- all` 已通过：223 项测试，0 失败、0 跳过；真实基础、组合与手机旅程通过，11 页共 44 张桌面及手机原图已查看。时限元数据另核对了 62 份原题本。验证 CLI、项目 Skill 图谱和 GitHub Actions 已同步，远端 CI 尚未执行。本文件为本地 PR 草稿。
