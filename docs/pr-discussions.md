# 为真实成绩报告增加持久化试卷讨论

考生查看成绩后，可以围绕同一试卷发表组合文字、图片、语音和链接的评论。讨论按 `paperId` 聚合，并保留发言时的版本号；服务端验证本机真实提交凭证，示例报告不进入真实讨论。

评论存入父目录的 `features.discussions`，通过串行事务持久化。客户端标识支持并发与响应丢失后的幂等重试。昵称复用本机身份，头像使用本地首字与稳定配色；独立头像工具为网络图片提供加载失败回退。图片和音频先规范化，再由服务端检查实际字节、PNG 解压像素和 WAV 时长。页面转义文本，仅渲染安全链接；失败保留编辑内容与既有附件。

录音支持权限失败恢复、停止、取消和最长 60 秒自动停止，在路由离开、延迟授权完成和销毁时释放音轨。图片通过现有模态框查看，音频使用原生控件。所有新样式和事件使用 discussions 前缀，沿用现有页面设计。

验证包含 9 项服务与媒体测试、6 项 Chromium 浏览器测试，15 项全部通过，无跳过。已验证组合媒体发表、服务重启读取、失败回滚、响应丢失重试、非法媒体与链接拒绝、昵称复用、头像回退、分页、焦点与播放节点保留、320–1440px 无横向溢出。浏览器录音测试使用生成的真实音轨，执行原生 MediaRecorder 与编解码；实体麦克风、系统权限弹窗和 Safari 尚待集成后验证。

已执行仓库 `npm test`，结果为 118 项通过、0 项失败、7 项跳过。跳过项来自其他任务的纠错浏览器与 Excel 环境检查，讨论区 15 项均实际执行。该结果只对应本次运行时的共享工作区，后续公共接入仍需协调对话复验。

本地交付包括独立模块、测试、Issue 与方案文档。公共入口、结果页挂载点及 8 MiB 请求限额的接入方式见 `docs/integration-discussions.md`。公共接入后的真实提交链、日常目录重启恢复和全站回归尚未由本模块验证。
