# 公共集成方案

服务端继续使用 Node.js 和本机 catalog.json。选岗、讨论及纠错各自管理 features 中的独立命名空间，版本、答卷、审计和扩展数据共用串行事务。落盘失败时同时回滚，避免已订正答案和旧成绩并存。

浏览器入口只注册一次各模块，按路由读取最新数据。个人记录页的岗位提示放在身份区域之后；整体分析入口放在同卷分析之前。结果页以估分与题型表现为主，之后展示 VS、纠错和讨论区域。排行榜及统计页由对应功能模块提供完整视图。管理页将纠错审核和岗位目录放在套卷长列表之前。页面继续使用现有配色、卡片和原生控件。

`POST /api/attempts/sync` 根据本机凭证返回最新服务端答卷。客户端校验后替换相同编号的评分快照，保留本机认领与参与选择。路由、审核结果和恢复备份后可调用同一同步操作。

浏览器交互通过临时端口和独立数据目录验证。原有 Node.js 测试、构建与新增的功能测试共同组成回归，截图保留手机和桌面主要页面。并行模块接口与文件归属见 [实现约定](parallel-feature-contract.md)。
