# 成长分析与主题筛选

报告继续保持首刷隐藏、二刷 VS、三刷短曲线。独立分析页把核心指标和紧凑记录表分开，单次使用进度环，多次显示真实时间曲线。记录行保留卷名、日期与对齐数值，图标替代重复机构文字。

二刷对比由两张小成绩纸卡组成，分别承载上次与本次总分；中间保留 VS，总分变化使用方向图标和精确数值。得分率、正确率各用一枚紧凑指标卡。所有实际板块按题目顺序显示为两列变化小卡，当前得分率为主值，上次得分率为次值，用填充与刻线比较前后位置，角标表示百分点变化。零变化显示「持平」，缺失指标显示「—」。上一刷成绩仍可打开原报告，右上角进入完整分析，第三次起仍保留真实时间曲线。

题型采用两列点选；长来源列表使用 beUI Input。日期采用 React DayPicker 10.0.2，保留成熟键盘及日期逻辑，日历按钮复用 beUI Button，并应用暖纸卡颜色、圆角和字号。

计分分组更名为计分口径，以真实来源、题量和满分区分。板块题数和满分放入按需展开的表格；完整兼容签名继续决定可比范围。官方材料的核对结论和来源见 [计分口径核对](scoring-reference.md)。正式交卷和答案订正自动计分；示例标记为静态「示例估分」。
