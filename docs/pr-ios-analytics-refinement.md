# 精简报告分析与核分状态

首次没有可比记录时，报告直接衔接原生雷达与板块卡。二刷显示总分前后对照、实际变化和最多三项题型变化；第三次起增加短曲线。报告中的完整筛选、技术规则编号、时间明细和全历史表已移至独立分析页。

成长分析页新增原生 beUI 组件，使用 Tabs 切换指标，BottomSheet 选择题型、评分方案、来源、日期和记录范围。曲线与紧凑逐次表使用相同的真实快照；保留长序列、同时间记录、键盘选点、搜索与分页。评分依据只在方案列表内按需展开。

评分、兼容签名、比较对象及图形坐标仍来自 `src/analytics.js`，没有新增计分实现或成绩缓存。原生成绩、分项、雷达和分享继续沿用当前组件；摘要后新增独立订正状态宿主。

待核分状态收在原卡标签旁，以小刷新图标和短按钮触发重新核分。分享导出只保留静态小标记。旧调用和已核分状态保持原卡外观，空排名逻辑保持。
