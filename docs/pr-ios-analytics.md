# iOS 结果页接入真实成长分析

用户使用的 `/ios-v3/` 页面需要直接展示已实现的同卷对比和成长分析。本轮新增 iOS 包装，复用原有评分兼容、上一刷选择、趋势与筛选逻辑，从服务状态读取真实提交，并将模块内链接交给 iOS 导航。

原生成绩摘要后增加分析挂载点。结果与分享组件接受空排名和真实满分；未参与时明确显示“未参与排名”，短卷按实际正确、错误数量和板块数据展示。报告、雷达图和分享海报继续使用现有 beUI 组件与纸卡样式。

新增样式限于分析宿主，使用现有字体、白底、深灰正文和浅珊瑚色。组件专项构建输出到临时目录，完整 bridge 也已在内存中编译，公共 vendor 由协调对话统一构建。

专项测试 12 项全部通过，覆盖空排名、零人数、实际排名、70/120/37.5 分满分、默认旧调用、五题卷、动态板块数、宿主位置、服务端快照、同规则跨卷、异规则隔离、订正更新、未来记录排除及样例隔离。真实浏览器通过临时端口的 `/ios-v3/` iframe 验证组合外观、导航、键盘、筛选及窄屏适配。

```bash
node --test test/ios-analytics*.test.js
```

UI 类型检查、现有 bridge 的 2 项测试、历史模型的 4 项测试、板块数据的 1 项测试均通过。实际 4781 端口与正式提交、榜单、审核重算后的组合验收由协调对话完成。接入细节见 `docs/integration-ios-analytics.md`。
