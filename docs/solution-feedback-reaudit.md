# 按原始批注补齐界面与状态

计时分别保存套卷与自定义的编辑上下文。切换来源恢复其选择、模块分钟和顺序；新用户仍先选卷。缩减设置头部，给模块留出可滚动空间，输入滚动避让固定操作栏；进入运行状态时重置滚动，并明确总用时、整卷计划和当前模块的关系。列表与单题统一使用可见的存疑／待检查含义。

评论底栏保留文字入口和独立照片图标。草稿按身份、试卷和回复对象保存到有大小限制的浏览器存储，刷新后恢复；同内容重试保留幂等标识。回复加入简短内容摘录，调整正文、动作与元数据层级，保留自动链接和照片。

排名的查询范围和标签取同一状态：无岗位时使用全国，已有岗位时保留用户明确选择的范围。卷身份带上实际系列与地市／副省变体。分享、VS、逐题比例、成长表格和返回按各自原始批注复验。

画廊动效重新从当前实际界面录制，统一使用指定 Logo。源文件就绪后统一构建，补齐上述失败场景的回归，再运行完整验证并检查当前原尺寸截图。逐项清单只在本轮实际结果支持时关闭。

最新计时选卷支持层级左滑返回，条目用同字号单行。三档推荐按钮按最新批注移除，整数直接输入与微调保留。

反馈入口先定位题目，显示本人和参考选项，以纸卡单选与依据提交；复盘保留待检查筛选和板块选择。分享将年份并入身份、品牌置为水印，并移除四种海报的估分小标题。成长入口按考试类型组织，兼容计分权重仍独立保留，未明确类别的卷不凭题数推断。

按最新标注进一步覆盖面板上方遮罩左滑的鼠标与触摸，保证只退一级并清理事件；反馈取消／提交以同一行显示，隐藏单选输入覆盖完整选项触区。雷达按真实导出倍率生成足够像素，保留高 DPR，避免水印海报中的图表被放大模糊。

最新分类以产品题量规则为准：130题地市、135题副省。类别是唯一类别筛选，同类分值入口和子组状态移除；归并对应类别的实际练习，并保留每次本卷得分、满分、正确率和题型分母。
