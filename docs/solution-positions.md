# 岗位目录与练习榜方案

## 数据与导入

内置 2027 国考目录来自已下载的招考简章 Excel。保留原压缩包、来源页面、公告页面、下载地址、获取日期和 SHA-256。Python 导入器支持 `.xls`、`.xlsx`，按工作表寻找表头，自动匹配常用国考、省考列名，也允许显式映射列名。岗位编码和部门编码保留字符串；Excel 数值单元格只接受安全整数，使用明确的补零格式恢复前导零。`.xlsx` 公式编码、科学计数法文本和超过可靠精度的数值拒绝导入。旧 `.xls` 读取缓存值，无法据此识别公式。

岗位标识由考试、年度、地区、部门编码或部门名称、岗位编码组成。同一标识重复时拒绝整次导入并列出工作表与行号，不静默合并。跨年度、跨省、跨部门的同码岗位分别保留。所有记录标注原工作表与行号，完整报考条件以保留的官方原件为准。

服务端默认只读内置目录，自定义目录与个人选岗、公开参与信息保存在 `features.positions`，统一通过公共 `mutateCatalog` 持久化。浏览器分块上传 Excel 或规范化 JSON，每块小于公共接口的 1 MB 上限，完整解析和校验成功后才原子发布。Python 仅为 Excel 导入的可选工具，应用运行及已导入目录无需 Python 依赖。

## 排行与个人设置

浏览器的 `guestId` 作为本机身份凭证。参与接口只接受服务端已存在且归属该身份的答卷 ID 与匿名昵称；不接收客户端分数。成绩从当前 receipts 读取，每次请求重新计算，因此答案订正后的重算立即生效。总分、题型各自取参与答卷中的最佳成绩，零分有效，同分并列并跳号，等分最佳选较早提交。公开响应不包含 guestId、答案或完整报告。

岗位选择独立于榜单筛选，修改岗位会把该身份已参与的答卷归入新岗位，全国参与不受选岗与否影响。撤回只变更参与状态并保留私人答卷。浏览器缓存服务端选择用于渲染，重新进入页面时再次读取服务端状态；失败保留原选择并展示重试。

## 页面方案

沿用现有 `src/ui.js`、`styles.css` 的紫粉配色、卡片、按钮、原生表单和原生 dialog，不引入组件框架。个人记录页岗位区域展示当前岗位年度、部门、名称和编码，未选岗显示一条提醒与选岗入口。提交前未选岗使用同一弹窗，可去选岗或明确跳过本次提醒，重试不会循环拦截。

```text
我的练习记录：当前岗位 / 尚未选岗                         [选择或更换岗位]
选岗弹窗：    年度  考试  地区    [搜索部门、岗位或编码] [搜索]
              部门 · 岗位名称 · 地点 · 编码               [选择]
              来源年度与链接                       [上页] 页码 [下页]
练习榜：      套卷与版本 / 总分或题型
              [我的岗位] [全国] [查看其他岗位]             [参与选择]
              名次     昵称     个人最佳成绩
```

目录采用搜索和 20 条分页，不把全部岗位塞进 select。弹窗复用公共 `openModal`，保留标签、键盘操作、Escape 和原生焦点约束。320px 窄屏筛选纵向排列，岗位长名称换行，分数与选择按钮保持可见。榜单空态直接说明当前范围没有参与成绩；服务错误提供重试。参与选择支持勾选已提交答卷，失败保留勾选。

管理区域显示当前目录及来源，文件导入填写年度、考试、地区和来源信息。导入中禁用重复提交，成功显示条数，失败保留文件和输入。对导入来源只显示真实提供的信息，用户导入文件不自动获得官方认证。

## 实施与验收范围

岗位模块、专用数据与脚本、`test/positions*.test.js` 和本任务文档由本任务修改。公共入口及其他模块由协调对话接入，精确方法写入 `docs/integration-positions.md`。模块行为测试使用独立临时目录和端口；验证持久化、重启、参与和撤回、真实凭证归属、并列、维度最佳、零分、跨年度、分页和导入失败回滚。浏览器验证先运行独立模块测试入口，再由公共集成验证我的记录、提交与榜单完整路径。
