## 一、视觉语言（贯穿全局）

| 维度 | 取值 | 用途 |
|---|---|---|
| 主色 | `#2C3E50` 深蓝灰 | 导航栏、选中态、主按钮、标题 |
| 强调色 | `#F5D08A` 暖黄 | 答题 CTA、得分卡背景、NEW 徽标、滑块轨道 |
| 危险色 | `#E74C3C` 红 | 错误数、删除按钮 |
| 成功色 | `#4CAF50` 绿 | 正确数、交卷确认按钮 |
| 背景 | `#F5F7FA` 冷灰 | 页面底色 |
| 卡片 | `#FFFFFF` + 1.5px `#B8C4CE` 描边 + 圆角 16px | 全部信息卡 |
| 字体 | 无衬线，标题 32–56px / 正文 28px / 说明 24px | 大字号，移动端远距离可读 |

**关键特征：描边卡片体系**。全站没有用阴影做层次，而是靠「白底 + 深灰描边 + 圆角」形成统一的实体卡片感，配深蓝灰文字。这套体系在答题卡、结果页、工具页反复出现，辨识度很高。

## 二、页面骨架

### 1. 首页 `pages/index/index`
- 大标题「**模拟卷刷题**」，56px 粗体，左对齐，下方留白很大
- 信件入口：圆形信封图标 + 「致考公小伙伴们的一封信 —— from独立开发者」，软性内容前置
- **题库切换胶囊**：`🥜题库` 标签 + 右侧双段分段控件 `超格 | 粉笔`（当前项深色填充）
- 套题卡片列表：每张卡 = 左上角 `展开` 小标签 + `NEW` 黄标 + 花生 emoji + 标题 + 右侧圆形箭头按钮
- `加载更多套题` 描边按钮（无填充）
- `常用工具` 分组标题带左侧圆点，四个入口：FB排版工具 / 官媒搜索 / 备考计时器 / 数学计算，每项 = 标题 + 副标题说明 + 圆形箭头

**设计要点**：箭头按钮是「进入」的强信号，整卡可点；用 emoji（🥜）做系列标识，零成本区分套题来源。

### 2. 答题方式选择（底部弹层）
- 遮罩 + 底部圆角面板
- 标题「选择答题方式」+ 副标题（当前套卷名）
- 两个大卡片选项：
  - **手动录入**（白底描边）：在手机上选择或修改答案
  - **扫描识别**（深色填充，视觉上更"高级"）：只能使用专用答题卡 + 内嵌「A4专用答题卡下载」白色按钮
- 底部 `取消` 文字按钮

**设计要点**：用填充/描边区分主次，把"重"选项做深色；卡片内嵌二级按钮解决"选之前先下载"。

### 3. 答题页 `pages/exam/exam`（`正在答题`）
- 顶部横向章节 tab：`逐题` 胶囊（带图标） + 政治理论 / 常识判断 / 言语理解 / 数量关系…（当前 tab 深色填充，可横向滑动）
- 章节标题「政治理论」+ 右上角 `共 20 题`
- 答题卡：每行 = 大号题号 + A/B/C/D 四个方形选项按钮
  - 未选：白底 + 描边 + 深色字母
  - **已选：深色填充 + 白色字母**（色块整体反转，对比极强）
- 底部：`下一章` 描边按钮 + `交卷 / Submit` 深色实心按钮
- 交卷确认弹窗：`提示` / 「还有 127 道题未做，确定交卷吗？」/ `继续做题` 灰底 + `交卷` 绿底

**设计要点**：选项按钮做成立体描边方块（有下投影感），手指点按目标大；题号与选项同行，一屏可见 7 题，信息密度高。

### 4. 结果页 `pages/result/result`
- 顶部胶囊标签：套卷名 + 期数
- 右上角 `保存图片` 图标按钮
- **得分卡**：暖黄圆角卡，超大分数 `0.0` + `分`，下方两行「超越 5.8% 对手」「参考排名: 1002 / 1064」
- 三栏统计：`0 正确`（绿）/ `3 错误`（红）/ `127 未做`（深灰），数字极大、标签极小
- **英雄榜**：🏆 标题 + 右侧 `登录：完善信息` 头像胶囊；列表项 = 排名徽章（金/银/铜圆）+ 头像 + 昵称 + 时间 + 分数；右侧柱状图小图标按钮；底部 `查看前十名` 文字链接
- **逐题选项分布**（滚动中部）：每行 = 题号 + 四个选项格，每格显示 `字母 百分比 (人数)`，正确选项绿底高亮
- **章节统计卡**：`常识判断` + 右侧胶囊 `0 / 15题 | 正确率: 0.0%`，下方虚线分隔
- 底部固定双按钮：`返回首页`（白）+ `发现错误`（深色）

**设计要点**：得分卡用暖色与全站冷色形成唯一焦点；逐题分布把"多数人怎么选"数据化，是差异化功能；章节卡的可折叠设计（`sectionCollapsed`）节省纵向空间。

### 5. FB 排版工具 `pages/fb-tool/fb-tool`
- 大图标卡 + 标题「粉笔排版打印助手」+ 副标题「电脑端使用 · 全动画手把手引导」
- 说明段落
- `最短使用路径`：深色代码块展示 URL（等宽字体，自动换行）+ 绿色 `📋 复制网址` 按钮
- **三步流程条**：`1 复制网址` → `2 电脑浏览器打开(Edge/火狐/Chrome)` → `3 照动画安装`，圆形序号 + 箭头连接
- `费用说明` 卡：🎁 完全免费
- 页脚免责声明

**设计要点**：三步图示用「圆序号 + 箭头」讲清楚跨设备流程，解决了"手机上看到电脑工具"的认知断层。

### 6. 官媒搜索 `pages/idiom/idiom`
- 顶部红色胶囊标签 `官媒语料 · 成语检索`
- 大标题「成语例句检索」+ 两行说明（列出人民网/人民日报/光明网/党建先锋）
- 搜索行：大圆角输入框 + 右侧红色 `检例句` 实心按钮
- `试试：` + 三个热门词胶囊
- 结果卡：来源 logo 方块（红色 `民` 字）+ 来源名 + `人民网·搜索平台` + 右上 `命中 15 条·去重后 5 条`
- 例句编号列表，**命中词红色高亮**，下方灰色出处 `中国共产党新闻网#理论 2022/10/27` + 标题 + 右下 `阅读全文 ↗`

**设计要点**：红色系局部颠覆主色，暗示"这是一个独立的查询工具"；命中数/去重数给用户预期管理。

### 7. 备考计时器 `pages/timer-setup/timer-setup`
- 顶部：`⏱ 目标时间 120 分钟` 卡 + `本地记录` 按钮
- 分段控件：`模块 | 总时间 | Both` + `开始计时 ▶` 深色按钮
- 模块列表，每行 = 模块名 + 红色 ✕ 删除 + `- 30 +` 步进器 + 滑块（0M—30M—60M）+ 右侧拖拽手柄（三条横线）
- 总时间自动汇总

**设计要点**：滑块与步进器并存，兼顾粗调和精调；拖拽手柄暗示可排序；顶部实时汇总目标时间。

### 8. 计时页 `pages/timer/timer`（横屏 · 沉浸式）
- 黑底/浅底极简，**超大等宽数字** `00:00:23`（约 120px），下方小字标签
- 中部胶囊 `点击时间切换样式`，点击后在「总用时+分模块」与「仅模块名+时间」两种排版间切换
- 右侧竖排模块导航：`1 资料分析 30M` / `2 判断推理 35M` …，当前项高亮描边
- 底部：圆形 `⏸/▶` 暂停按钮（暖黄填充）+ 圆形 `✓ 1s` 结束按钮（长按确认，标注 1s）
- 最底部进度条 `TARGET: 30M` … `ON TRACK`

**设计要点**：这是全站最好的一个页面。用「字号即层级」把信息压到最少；长按 1s 防误触；`ON TRACK` 状态文案把时间数据翻译成心理反馈。

## 三、可复用的交互模式

1. **深色填充 = 选中/主操作**：全站一致，无需额外说明
2. **描边卡片 + 圆角 16px**：信息容器统一语言
3. **圆形箭头按钮**：列表项进入的通用符号
4. **胶囊分段控件**：二/三选一（题库来源、计时模式、难度筛选 `全员/>60/>70/>80`）
5. **底部弹层 + 遮罩**：轻量选择（答题方式、登录、报告错误）
6. **长按 1s 确认**：破坏性/不可逆操作（结束计时）
7. **大数字 + 小标签**：所有统计场景（得分、正确/错误/未做、正确率）
8. **命中高亮**：搜索结果里把 query 标红
9. **三段式流程条**：跨设备/多步骤任务

## 四、信息架构

```
首页（模拟卷刷题）
├── 一封信（内容入口）
├── 题库 超格 / 粉笔  ← 分段切换
│   └── 套题列表（展开/折叠 → 套卷 → 历史 / 答题）
├── 常用工具
│   ├── FB排版工具获取      → 外部引导页
│   ├── 官媒搜索            → 成语例句检索 → 阅读正文
│   ├── 备考计时器          → 模块设置 → 计时（横屏）→ 训练分析报告 / 本地记录
│   └── 数学计算            → 百化分训练 → 练习结果
└── 我的（隐藏入口）
    ├── 所有用户（user-list）
    ├── 错误反馈列表（admin/report-list）
    └── 历史记录（set-history）

答题流程：首页 → 答题方式选择 → 答题页（章节 tab / 逐题）→ 交卷确认 → 结果页
结果页：得分卡 → 英雄榜 → 逐题选项分布 → 章节统计 → 返回/报错
```

## 五、给 RollieRank 的借鉴清单

1. **描边卡片体系**取代阴影，做统一的视觉识别
2. **深色填充选中态**，答题选项直接用整块反转，比描边高亮更明确
3. **逐题选项分布**（百分比 + 人数 + 正确答案绿底）——这是刷题类产品最有价值的数据呈现
4. **得分卡用唯一暖色**，其余全冷色，视线自然落到分数上
5. **`超越 X% 对手` + `参考排名`** 比单纯分数更能驱动复刷
6. **长按 1s 确认**替代二次弹窗，适合训练/计时类不可逆操作
7. **三段式流程条**处理"手机上看到电脑工具"这类跨端场景
8. **横屏沉浸式计时页**：字号即层级，底部把时间数据翻译成 `ON TRACK` 状态文案
9. **[v78] 能力雷达用「人群参考环」而不是裸画六边形** —— 把「我的表现」和「同分段平均」「更高分段平均」画在同一张图上，用户能立刻看出哪一维是短板。这比单独给一个总分更有指导性。
10. **[v78] 雷达图离屏渲染成 PNG 再叠加文字** —— canvas 画的文字在小程序里缩放会糊，把图形烘成图片、文字用 DOM 绝对定位叠上去，是保证可读性的实用技巧。
11. **[v78] 分享图「先预览再保存」** —— 生成后先进预览层，用户能切样式、能点开放大、满意了再保存到相册，比直接弹系统 ActionSheet 再闷头保存体验好得多。
