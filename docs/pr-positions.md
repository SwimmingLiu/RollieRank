# 岗位目录、Excel 导入与真实练习榜

原排行榜依赖固定样例，个人岗位和参与选择仅靠本机状态，无法比较服务中真实参与者的成绩。本次提供持久化选岗、全国与岗位榜、参与和撤回接口，成绩只取服务端 receipts，并保留同卷同版本、各维度个人最佳及并列规则。订正后的成绩重新读取即可生效。

内置目录采用已核验的 2027 国考原表，包含 19,426 个岗位、35,691 个招录名额，保留原压缩包、来源、日期、哈希和行号。可复用 Python 脚本支持国考、省考 Excel，处理字符串编码、前导零、合并单元格、列映射与重复标识。管理界面分块上传 Excel 或规范化 JSON，校验成功后才原子发布。

浏览器模块提供我的岗位、提交前选岗或明确跳过、分页搜索、榜单范围切换及参与答卷管理。查看其他岗位不改变个人选岗，失败保留搜索或勾选并支持重试，320px 手机布局可操作。界面沿用现有控件、原生 dialog 和紫粉样式。

23 项岗位专项测试全部通过，包含原始官方 XLS 完整重导入、真实 XLSX 上传解析、实际文件写入失败回滚、服务重启、成绩归属与实时重算。Chromium 验证了个人记录、提交提示、榜单和 JSON/Excel 导入的完整模块操作，并检查四种桌面/手机视口。全仓回归和构建日志保存在本任务验收目录。

接入方法和接口见 `docs/integration-positions.md`，导入操作见 `docs/import-positions.md`。公共入口及其他模块的组合回归由协调对话完成。Excel 解析需要可选的 Python 依赖；已导入目录与排行榜维持原有 Node.js 运行方式。旧 `.xls` 的公式使用缓存值，源表的岗位编码应优先保存为文本。
