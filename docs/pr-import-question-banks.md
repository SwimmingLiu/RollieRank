# 导入多机构套卷并按各卷规则估分

原导入脚本只支持旧目录中的 12 套固定 130 题卷，无法读取新增机构的扫描答案，也无法区分 120、130、135 题卷及附加题。现扩展来源提取和校验，新增 50 套主卷，本机目录按版本 ID 补入数据，保留原卷、历史提交和下线状态。

花生二期使用随卷分值表；超格、粉笔、上岸村使用明确标注的平台国考模块参考权重，按实际题量折算至百分制。计分、发布试算和演示榜使用一致的总分舍入规则，快照保存原始权重及规则，确保恢复和修订时口径一致。

源文件一致性检查、50 项自动化检查和构建均通过。浏览器已验证新增目录筛选、120 题卷留空提交、估分依据显示与刷新恢复。新参考答案文件通过静态访问隔离检查。
