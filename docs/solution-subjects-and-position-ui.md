# 统一显示与统计方案

判断推理使用共享模块归一显示名称、维度ID、报告分项与公开界面的题型。后台保留原始题型及逐题分值，岗位榜对合并后的分项计算个人最佳，分析按实际逐题权重统计，按题数计算正确率，不能平均四类百分比。旧版记录也在读取时使用同一显示规则。

选岗首层明确选择国考或省考，再按实际导入来源、地区和年度进入原有层级；只有一份国考表时仍保留考试入口。省考无目录时只呈现真实空态，后续导入即可出现在同一入口。提交提示把选岗用途合入短标题，保留两个等宽动作，取消仍不提交。

全局滚动条检查原生绘制与标准属性的覆盖关系，采用低对比暖灰、细线和更短的可见轨道；滚轮、触屏、键盘与原生拖动继续有效。使用真实1133×1054外层与320/390/430画板留存截图，验证来源切换、合并排名的分数及全量门禁。
