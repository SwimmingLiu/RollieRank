# 成绩对比与成长分析方案

分析只读取最新的 `state.attempts`。评分规则和成绩均从提交报告提取，每次渲染重新计算，不保存成绩缓存。

`src/analytics.js` 提供纯数据函数。规则签名采用排序后的规范 JSON，包含题型名称、各题型题量与原始权重分布、题型内按题号排列的权重序列、原始满分、展示满分、折算比例与舍入方式。原始权重取 `rawMaxCents ?? maxCents`，机构、套卷标题、规则标签、来源文件和参考答案不参与签名。题型编码允许机构自定义，按规范化后的完整题型名称对齐；名称不同则分别处理。报告缺少可验证权重时单独列出原因，不进入混合趋势。

上一刷限定为同一 `paperId`，评分签名一致，且 `createdAt` 严格早于当前报告。相同时间的记录以提交 ID 稳定排序并全部保留；时间相同无法证明先后，因此不会作为上一刷。答案修订号和版本标签不同但评分规则相同的同卷记录可以比较。

`src/features/analytics.js` 导出 `createAnalyticsFeature(ctx)`，使用独立的 `data-analytics-*` 委托事件。`statsView` 渲染同卷或整体分析，`afterRender` 挂载结果页对比与曲线，以及个人记录页入口。原生 `select`、日期输入、`details` 和按钮承担焦点及键盘行为，链接复用现有路由。

页面延用现有紫粉色变量、卡片和字阶。结果页先呈现上一刷与本次的三个主指标，再在同一张卡中展开题型对比。趋势页将筛选放在图表前，图表下保留日期、来源、得分、得分率、正确率和报告链接。评分依据按需展开，展示题型权重表。得分率与正确率以百分点显示变化，并明确标注进步、退步或持平。

曲线使用原生 SVG，按真实提交时间定位；同一时间保留所有点并附序号区分。每页最多 24 次，提供早一页、晚一页和范围选择，完整记录均可到达。图表使用可聚焦容器及左右方向键选择记录，Home、End 到达首末记录，数据表提供同等数据和报告入口。缺失题型显示缺失并在曲线中断开，单次记录仅作基线。结果页曲线截止当前报告，避免未来练习进入历史报告的比较。

测试使用 `node:test`，覆盖规则签名稳定性、原始权重、折算、题型分组、跨机构兼容与异规则隔离、上一刷时间边界、题型缺失、稀少与同时间记录、长序列分页，以及报告被重算后重新读取。独立浏览器夹具验证模块界面，公共入口接入与服务端同步后的整体验证交给协调对话。
