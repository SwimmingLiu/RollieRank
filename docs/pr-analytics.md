# 新增同卷成绩对比与成长分析

结果页现在可以比较当前报告之前最近一次兼容同卷练习的总分、得分率、正确率及各题型表现，并显示进步、退步或持平。同卷多刷曲线截止当前提交，避免未来记录进入历史报告的比较。

新增整体与题型分析，按时间查看同规则下每套卷的表现。评分兼容签名使用逐题原始权重、题型分组、题量、题型内权重序列、折算比例、舍入及额外计分配置。相同规则允许跨机构合并，不同规则分别展示，并可展开权重明细核对依据。

页面提供规则、统计范围、指标、来源套卷和日期筛选。原生 SVG 与逐次数据表保持相同数据，支持键盘选点、完整分页和窄屏横向滚动；题型或指标缺失显示为空，未形成多次记录时显示基线状态。

分析每次读取最新报告，不另存成绩缓存。答案重算后重新渲染即可更新当前报告、上一刷及所有曲线。示例报告保持独立，不进入个人趋势。

代码位于 `src/analytics.js`、`src/features/analytics.js` 和 `src/features/analytics.css`；模块导出 `createAnalyticsFeature`。公共入口接入、挂载点和旧比较区域的替换见 `docs/integration-analytics.md`。

专项测试 29 项全部通过，构建成功。最近一次全仓回归 119 项通过、7 项跳过；跳过项为其他模块的 6 项岗位 Excel 依赖检查和 1 项纠错浏览器用例。

验证包括纯数据、模块行为和真实 Chromium 用例，覆盖原始权重与折算、跨机构兼容、异规则隔离、上一刷时间边界、缺失题型、同时间多条记录、长序列、重算后更新、键盘与焦点，以及 1440×900、1280×800、390×844、320×844 视口。浏览器夹具使用实际模块和现有页面外壳，数据及端口与日常练习隔离。
