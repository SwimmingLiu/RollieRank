# iOS 选岗与真实排行榜

`/ios-v3/` 原有界面没有接入岗位服务，排行榜与报告名次仍来自固定数据。本模块复用已验证的选岗、提醒、参与和撤回流程，把真实 API 的 rows、self、count 传给原 beUI 排名组件，保留领奖台纸卡、字体和交互组件。当前试卷的题型动态生成，并列第一保留所有人，未参与和空榜使用空名次。

报告及分享通过 standing() 读取当前版本总分榜。浏览其他岗位只改变查看范围，个人岗位保持不变。原岗位工厂只增加返回副本的 snapshot()，旧入口兼容。

独立 iOS iframe 验证使用最新 ranking.tsx 的临时构建、真实 BottomSheet、实际服务核分的临时答卷和官方岗位目录。7 项 iOS 专项及 7 项原模块兼容测试通过，覆盖动态题型、真实取数、并列、未参与、提交提醒、搜索翻页、范围隔离、零分、失败重试、报告 standing 和撤回。既有 bridge 测试、历史模型测试和 TypeScript 检查通过，三种手机尺寸没有横向溢出。共享 vendor 保持由协调对话统一构建。

接入方法、props 与公共入口需要删除的旧演示路径见 `docs/integration-ios-positions.md`。4781 端口、iframe 公共路由、记录挂载、报告/分享 props 及四功能组合验收由协调对话执行。
