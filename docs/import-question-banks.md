花生沿用内部机构键“四海”，原有一期 ID 和答案数据保持不变。新增花生套卷的标题显示“花生十三”。主应用选卷页可按机构、期数和卷型筛选对应资料。

平台参考规则按题本实际模块配置政治理论、常识判断 0.5，言语理解、判断推理 0.8，数量关系、资料分析 1 的相对权重，最后折算为满分 100 分。该规则是练习估分依据，不代表官方逐题分值。总分在原始整数权重汇总后统一舍入，分项显示可能存在舍入尾差。

答案提取区分主卷与附加题，不复用附加题从 1 开始的编号。花生答案使用文本层，粉笔答案表经过逐表核对，超格答案使用两种识别设置交叉核对；上岸村从逐题解析的答案栏提取。上岸村第七套第 114 题的答案栏漏印，采用同一份 PDF 第 48 页解析明确给出的 A，并记录源文件哈希和修正依据。

`data/paper-import-verification.json` 保存各卷来源、页码、哈希和计分依据；`data/paper-ocr-review.json` 保存答案表核对和漏印修正证据。生成的参考答案位于 `src/data/`，不作为浏览器静态资源提供。

重新导入与核对：

```bash
python3 scripts/import-papers.py
python3 scripts/import-papers.py --check
npm test
npm run build
```

生成数据需要 Python 的 `pypdf`、`pymupdf`。扫描资料识别使用 macOS Vision 与 Swift，缓存保存在 `.local/paper-import/`；运行主应用只需 Node.js。
