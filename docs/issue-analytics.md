# 成绩对比与成长分析

现有结果页只展示同版本总分差，趋势页只保留最近 12 次同卷得分率。练习者无法同时比较上一刷与本次的总分、正确率和题型表现，也无法查看多套试卷中同一题型的变化。

不同机构的试卷可能使用同一评分规则，也可能只有满分相同。直接合并百分制成绩会掩盖题量、题型权重和折算方式的差别。历史答案纠正后，分析还需要跟随最新报告更新。

结果页需要展示当前报告之前最近一次兼容同卷练习的对比卡，以及截至本次的多刷曲线。分析页需要提供评分规则、整体或题型、来源套卷和日期筛选，并保留每次练习的数据。无可比记录、缺失题型、同一时间多条记录和长序列均需有明确呈现。

验收依据是实际报告：原始权重、题型分组、题量、折算规则共同决定兼容性；相同规则允许跨机构统计，不同规则分开。图表提供等价数据表和键盘操作，未记录的用时不进入分析。
