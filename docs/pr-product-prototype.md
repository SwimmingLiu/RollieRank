# 完成卷卷小榜产品原型

原 H5 只支持答案录入和可变报告，缺少选卷、提交历史、同卷复盘和管理入口。本次按产品与 UI 方案补齐电脑、手机共用的应用流程，保留 12 套真实数据及已有批量录入能力。

选卷首页优先恢复草稿，答题页隐藏导航并支持手机抽屉。正式提交通过本地服务评分，按独立凭证去重并冻结报告；再次练习和规则修订保留原成绩。报告区分得分率与正确率，先展示最弱三项，再提供明细、CSV、三类 PNG 和同版趋势。

参考答案从浏览器目录隔离，示例报告使用独立虚构答案。管理端支持任意 1–300 题单选卷的 CSV 校验、试算、草稿、版本发布、下线与审计；写入失败回滚内存。体验身份、认领、演示排行、撤回、备份恢复与删除均可操作。
