# 选岗、讨论、成长分析与纠错的公共集成

原型的排行榜使用浏览器演示记录，纠错只下载文本，历史成绩无法随答案订正同步。四项功能现已接入公共入口，使用真实提交凭证和同一持久化事务；审核通过后，旧报告、排行榜、成长分析和未来提交共同使用新标准。

## 已完成

| 功能 | 实际行为 |
| --- | --- |
| 选岗与排行 | 内置 2027 国考官方 19,426 个岗位；支持国考、省考 Excel 及 JSON 导入、首次提交选岗提示、个人默认岗位、全国及其他岗位浏览、真实参与和撤回 |
| 试卷讨论 | 正式提交后可组合发表文字、图片、语音与链接；头像本地回退、附件校验、失败保留输入、刷新和服务重启读取 |
| 成长分析 | 上一刷 VS、题型变化、多刷曲线、同规则跨机构趋势、来源和日期筛选、规则明细、分页、键盘选点及等价数据表 |
| 答案订正 | 多题反馈与试算、服务端凭证审核、待办和处理通知、原子订正和重算、重复审核与过期依据保护、审计与原始答卷保留 |

公共入口还统一了模块生命周期，离开报告时立即释放录音音轨，成绩同步失败也不会阻止释放。连续弹窗切换后保持键盘焦点，原操作被审核队列移除时返回主内容。机构入口在窄屏内横向浏览，新增机构不会撑宽页面。

`/api/attempts/sync` 只返回本机凭证对应的答卷。客户端校验并替换已有评分，保留本地认领和参与信息及订正历史。版本、答卷、扩展数据与审计在写入失败时整体回滚。讨论 JSON 限额为 8 MiB，其他请求保持 1 MiB。

## 验证

- 完整测试：130 项通过，0 失败，0 跳过。运行时为 Excel 指定含 openpyxl、xlrd 的 Python，并启用 `ROLLIERANK_BROWSER_TEST=1` 和对应 Playwright Python。
- 构建：`npm run build` 通过，浏览器产物继续排除参考答案目录。
- 公共源码应用：`scripts/verify-features.py` 的 15 项旅程全部通过。
- 构建后应用：同一脚本加 `--dist`，15 项旅程全部通过。

完整旅程覆盖未选岗提交与参与勾选、选岗恢复、二刷 VS、多刷曲线、跨机构规则分组、文字及图片／音频／链接组合评论、断网重试、录音离页释放、CSV 与三种不同 PNG、两题审核与权限拒绝、旧报告／排名／趋势同步、新答案提交和 JSON 备份恢复。9 类实际页面已保留桌面与手机截图，并检查控制台错误和横向溢出。测试使用独立端口、临时目录和虚构四题样卷，不操作日常练习数据。

源码旅程结果在 `test-results/features/results.json`，构建旅程结果在 `test-results/features-dist/results.json`；完整测试日志在 `.beauye/tasks/feature-integration/evidence/npm-test.log`。

## 运行边界

当前交付为本机 Node.js 原型，全国维度表示当前服务中的真实参与用户；微信登录、云端身份认证和跨设备服务未接入。维护者需配置 `ROLLIERANK_REVIEW_TOKEN` 才能审核，Excel 导入需要说明中的 Python 依赖。

录音已用浏览器生成的真实音轨验证原生 MediaRecorder、编解码和资源释放；实体麦克风、操作系统权限弹窗与 Safari 尚未在本次环境实测。仓库中原有未提交改动保留，本次未创建远端 Issue、PR 或发布版本。
