# 导入新增纸质套卷

当前导入脚本只识别四海一期的旧目录和固定 130 题。原始资料已按机构重新整理，并新增花生二期地市卷、副省卷、超格、粉笔和上岸村套卷；扫描版答案与合订解析不能直接作为文本导入。

需要从题本和答案资料建立可追溯的题库，保留原有套卷 ID、规则版本与历史成绩。新增资料须区分主卷、附加差异题和不同卷型，逐项校验题号、答案及题型。有随卷分值表的套卷采用原表；其他套卷按实际模块构成使用平台国考参考权重，折算为百分制，并在结果页说明计分依据。

导入应支持重复执行与源文件哈希校验。已有本机目录中的自定义卷、下线状态、审计和提交凭证须保留。不同题量的参考卷应在汇总原始权重后统一舍入，刷新、修订和重启服务均保持对应规则。
