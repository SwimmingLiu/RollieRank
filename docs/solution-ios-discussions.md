# iOS 试卷讨论适配方案

在成绩板块之后保留一个讨论纸卡，编辑器、附件、发表操作和评论列表共用现有讨论模块。包装层只处理 iOS 样式、成熟控件挂载与旧样例的正式核分引导，继续使用同源真实 API。

样式仅覆盖 iOS 讨论挂载点。采用当前白色表面、深灰文字、浅珊瑚反馈和原有 Nunito/FangYuan 字体，按钮保持 44px 触达尺寸。链接和附件帮助按需展开。原生文件选择与音频控件保留浏览器行为，图片预览通过 `ctx.openModal` 交给现有 beUI BottomSheet。

根模块没有固定 `#modal` 依赖，无需复制服务交互、媒体校验或录音状态。iOS 包装保留其生命周期，并在异步 DOM 更新后挂载现有 beUI Button。讨论头像通过独立 React island 复用当前 `ui/primitives.tsx` 的 Avatar；补充加载期间的本地回退，网络失败交由现有 Avatar 回退。每次 DOM 替换后清理脱离文档的 island，销毁时统一释放。

旧样例沿用 `isSample:true`，不读取或发表真实评论。已匹配真实公开版本时引导打开该卷录入并核分，缺少版本时引导回记录选择正式试卷。任何示例分数都不转为真实提交。

专项测试使用 `/ios-v3/` 包装页和 iframe、现有纸卡样式、临时编译的真实 beUI 组件以及临时目录中的真实 API。验证组合评论持久化、失败输入保留、头像与图片 BottomSheet、样例隔离和 320/390px 宽度。公共 4781 服务、导航、bridge 最终导出与四项功能组合由协调对话接入后验证。
